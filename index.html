▸ 소재 자동 발굴 (보조 기능 — 소재가 없을 때만. 누르면 펼치기)

권장 워크플로우는 아래 ‘기사 링크’에 직접 URL을 붙여넣는 것입니다. 이 자동 발굴은 소재가 마를 때 보조로만 쓰세요. 메이저 매체 = The Sun·Daily Mail·CNN·BBC·Guardian·NY Times·UPI·NASA 등. "(블로그)"·"(큐레이션)"은 신뢰도가 낮아 기본 선택에서 빠져 있습니다.
[새 소재 크롤링]을 누를 때마다 순서를 섞고 새 기사 위주로 보여줍니다.

1. 소재 입력 — 메인: 기사 링크를 붙여넣으세요

직접 고른 기사 링크를 넣는 게 가장 정확합니다. 본문을 자동 추출해 아래에 채웁니다. 일부 사이트는 차단될 수 있으니, 그 경우 본문을 직접 붙여넣으세요. (소재가 없으면 위 ‘소재 자동 발굴’을 펼쳐 쓰세요.)
기본값 = 한국·일본·미국 3개국 집중
캡션 구조: 훅 → 구체적 실화 사례 → 의학 배경 설명 → 전문가 권고 → 권위 출처 인용(예: The Sun, ○○학회) → 팔로우 CTA. 니치 선택 시 발굴 소스도 의학 전용으로 전환됩니다.
사진 1장에 강한 후킹 헤드라인을 얹고, 본문은 캡션에 넣는 방식. 사진 1장이라 릴스(음원)로 그대로 쓰기 좋습니다.

2. 표지 이미지 & 스타일

클릭 또는 드래그해서 이미지 업로드
※ 무료 라이선스(Pexels/Unsplash) 또는 직접 촬영·AI 생성 이미지 사용
G마켓 산스 = 이슈·바이럴 카드의 대표 서체
원본성 안내 — 이 도구는 기사 내용(사실)을 AI가 새 문장으로 재작성합니다. 타인의 게시물 캡처를 그대로 재업로드하는 용도로 쓰지 마세요. 메타 원본 콘텐츠 정책 위반으로 계정 제재 대상이 됩니다. 이미지는 라이선스가 확보된 것만 사용하세요.

3. 결과 미리보기 & 복사/다운로드

소재를 입력하고 [카드뉴스 생성]을 누르면 미리보기가 나타납니다.
카드 이미지를 클릭하면 클립보드에 복사됩니다.
이미지 클릭 = 클립보드 복사 (인스타 웹/PC앱에 바로 붙여넣기 가능) · 다운로드 버튼 = 파일 저장. 모바일 업로드는 카카오톡 "나에게 보내기"로 파일을 옮기면 편합니다. 생성 비용: 회당 약 $0.01~0.03.

4. 릴스 만들기 — 방금 만든 카드뉴스를 세로 영상으로 이어붙여 비팔로워에게 도달

왜 릴스인가 — 카드뉴스(캐러셀)는 주로 이미 나를 팔로우한 사람에게 도달합니다. 새 유입은 릴스가 만듭니다 (릴스탭·탐색탭 노출 → 프로필 방문 → 팔로우 → 그때부터 카드뉴스가 그들에게 도달). 아래에서 현재 언어 탭의 카드들을 9:16 세로 영상으로 자동 변환합니다.
음원 팁 (꼭 읽으세요) — 인스타 인기 음원은 앱에서 직접 올릴 때만 붙일 수 있고, 릴스 도달에 가장 큰 영향을 줍니다. 최대 도달을 원하면 [MP4 저장] → 인스타 앱에서 릴스로 올리며 인기 음원 선택을 권장합니다. 아래 "배경 음원"은 저작권 free 음원을 영상에 직접 입힐 때만 사용하세요 (API 자동 게시용).
무료 음원: YouTube 오디오 보관함 · Pixabay Music · Uppbeat. 인스타 인기 음원은 여기에 넣지 말고 앱에서 올릴 때 선택하세요 (여기 넣으면 저작권 제재 위험 + 인기 음원 도달 부스트 못 받음).
권장 경로 — 저장 후 인스타 앱에서 릴스로 올리며 인기 음원 선택 = 도달 최대화
API 게시는 동영상 호스팅(Cloudinary) 필요 · 인기 음원 불가

5. 내 영상으로 릴스 만들기 — 영상 상단에 강력한 제목(흰 라벨 + 노란 강조)을 얹어 9:16 릴스로

원본 영상 상단에 강력한 제목만 얹습니다(기사 본문 자막은 넣지 않습니다). 스타일은 흰색 라벨 박스 + 큰 제목(핵심 줄은 노란색) — 스크롤을 멈추게 하는 그 스타일입니다. 기사를 넣으면 제목을 자동으로 만들고, 직접 수정할 수 있습니다.
원본 영상의 소리는 그대로 유지됩니다 — 삭제하거나 임의로 편집하지 않습니다.
속도 팁 — 녹화는 영상 길이만큼 실시간으로 진행됩니다. 시작/끝을 15~30초로 트림하면 훨씬 빠릅니다. 완성 후 [저장] → 인스타 앱에서 릴스로 올리며 인기 음원을 얹으면 도달이 커집니다.

인스타그램 게시물 보너스 자격 조건

계정별로 아래 조건을 모두 충족하면 인스타그램 앱 내 계정 설정에 "보너스 신청" 탭이 자동으로 뜹니다 (이 도구에서 신청하는 게 아니라 안내용 체크리스트입니다).

· 만 18세 이상, 한국 등 지원 국가 거주
· 프로페셔널(크리에이터/비즈니스) 계정
· 최근 3개월 누적 조회수 100만 회 — 화면에 노출만 돼도 조회로 인정되어 유튜브보다 달성이 쉬움

단일 사진과 카드뉴스(캐러셀) 모두 대상이지만, 알고리즘은 체류 시간을 봅니다 — 옆으로 넘겨야 하는 카드뉴스가 유리해서, 위 "마인드셋·자기계발" 니치는 자동으로 카드뉴스 포맷을 씁니다. 번역·불펌은 노출 감소 대상이니 이 도구처럼 AI로 재작성된 콘텐츠만 발행하세요.

인스타그램 계정 (언어별 발행)

각 언어는 여기서 매핑한 계정으로 발행됩니다 (한국어 → 한국 계정, 영어 → 영어 계정 …). 계정마다 비즈니스/크리에이터 전환 + 액세스 토큰이 필요해요. 아래 이미지 호스트·소스 설정은 모든 계정 공용입니다.

공용 — 이미지 호스팅 & 소스

ImgBB: imgbb.com 가입 → api.imgbb.com 접속 → "Get API key" → 키 복사해서 위에 붙여넣기. 이게 전부입니다.
Pexels: pexels.com/api 접속 → 가입 → "Your API Key" 복사. 무료·무제한에 가깝고, 모든 사진이 상업적 사용 가능 라이선스라 수익화에 안전합니다.
Cloudinary: Settings → Upload → "Add upload preset" → Signing Mode를 Unsigned로 저장 → preset 이름 입력.
