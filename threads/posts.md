# id: 01-result-hook
# day: 1
기사 링크 하나 붙여넣고 3분 기다렸더니 카드뉴스가 10개 언어로 나왔다.

한국어 일본어 영어 독일어 스페인어…
번역이 아니라 언어별로 새로 쓴 문장이다.

손으로 만들 땐 한 세트에 두 시간 걸렸는데.
===
# id: 05-failure
# day: 1
인스타 다국어 계정 만들다가 배운 것.

번역기로 돌려서 올린 계정은 도달이 안 나왔다.
같은 내용을 언어별로 새로 쓴 계정은 나왔다.

메타는 번역·불펌을 걸러낸다.
"다국어로 올리기"가 아니라 "각 언어로 다시 쓰기"가 맞는 접근이었다.
===
# id: 02-problem
# day: 2
인스타 계정이 안 크는 이유, 전략이 아니라 생산량이었다.

카드뉴스 한 세트 =
소재 찾기 + 문장 쓰기 + 이미지 고르기 + 자르기 + 캡션 + 해시태그
= 두 시간

그래서 주 2~3회에서 멈춘다.
알고리즘 문제가 아니라 체력 문제였다.
===
# id: 03-hook-patterns
# day: 2
스크롤 멈추게 하는 카드뉴스 제목, 패턴이 정해져 있다.

1. 숫자 + 반전 — "3주 만에 끊었다"
2. 손해 회피 — "이거 모르면 계속 손해"
3. 미완성 문장 — "의사가 말을 아끼는 이유는"
4. 통념 부정 — "물 많이 마시면 안 되는 사람"
5. 구체적 시점 — "어제 발표된 연구에서"

이걸 10개까지 채워두면 소재가 안 마른다.
===
