# 판매 채널 등록 문안

크몽·스마트스토어·자체 판매에 그대로 붙여넣는 문구입니다.
`「」` 자리만 채우면 됩니다.

> **전 채널 공통 원칙**
> 수익·조회수·팔로워를 보장하는 문구는 어디에도 쓰지 않습니다. 표시광고법 위반
> 소지가 있고, 분쟁이 나면 전액 환불 대상이 됩니다. 파는 건 **제작 시간**입니다.

---

## 1. 크몽

전자책은 크몽에서 **전자책·템플릿** 카테고리로 등록합니다. 서비스 심사에 보통
1~3영업일이 걸리므로 다른 준비와 병행해서 지금 신청해 두십시오.

### 서비스 제목 (40자 내외)

```
기사 하나로 인스타 카드뉴스·릴스 20개 뽑는 프롬프트 팩 드립니다
```

대안:

```
인스타 다국어 카드뉴스 대량 발행 실전 가이드 + 복붙 프롬프트 드립니다
```

### 서비스 설명

```
■ 이런 분께 필요합니다

인스타 카드뉴스를 직접 만드시는 분이라면 한 세트에 두 시간쯤 쓰실 겁니다.
소재 찾고, 문장 새로 쓰고, 이미지 고르고, 자르고, 캡션에 해시태그까지.
주 3회면 주당 여섯 시간입니다. 본업이 있으면 거기서 멈춥니다.

계정이 안 크는 이유를 대부분 전략에서 찾지만, 실제로 막히는 지점은 생산량입니다.
알고리즘 문제가 아니라 체력 문제이고, 체력 문제는 전략으로 안 풀립니다.

■ 무엇을 드리나요

PDF 한 권(A4 14쪽)입니다. 본문 7장과 부록 2개로 구성됩니다.

1장. 병목은 전략이 아니라 생산량입니다
  - 제작 다섯 단계를 시간으로 분해하고, 무엇을 기계에 넘길 수 있는지 가릅니다

2장. 후킹 — 3초 안에 엄지를 멈추는 7가지 패턴
  - 반전 / 충격 숫자 / 금기 직설 / 미스터리 / 최상급 / 경고 / 정체 공개
  - 각 패턴의 문장 골격과 글자 수 기준까지

3장. 캡션 — 니치별 검증된 구조
  - 일반 바이럴(2모드), 의학·건강(2템플릿), 연예, 마인드셋
  - 니치마다 문단 단위로 고정된 틀을 드립니다

4장. 다국어 — 번역하면 죽습니다
  - 번역과 현지화의 차이를 다섯 항목으로 비교
  - 프롬프트에 넣을 지시문 그대로 포함

5장. 계정을 지키는 세 가지 규칙
  - 원본성, 주어·목적어 사고 방지, 이미지 라이선스

6장. 인스타그램 게시물 보너스 — 지표는 하나입니다
  - 왜 단일 사진보다 캐러셀이 유리한지

7장. 자주 나는 실수 8가지
  - 증상·원인·고치는 법을 한 표로

부록 A. 복붙 프롬프트 전문  ← 이 책의 핵심입니다
  - 공통 브랜드 보이스 + 지적재산권 가드
  - 일반 바이럴 / 의학·건강 / 마인드셋 카드뉴스
  - 소재와 언어 자리만 채우면 바로 돌아갑니다

부록 B. 하루 운영 루틴
  - 세팅이 끝난 뒤의 하루를 55분으로 쪼갠 표

■ 미리 말씀드릴 것

· 수익을 보장하지 않습니다. 조회수도, 팔로워도, 보너스 승인도 약속하지 않습니다.
  그건 소재 선택, 니치, 발행 빈도, 계정 상태, 알고리즘에 달려 있고 제가 통제할 수
  없습니다. 이 자료가 파는 건 제작 시간입니다.

· 제 계정 실적은 자료에 없습니다. 내세울 게 아직 없기 때문입니다. 대신 들어 있는 건
  도구를 만들면서 실제로 부딪히고 고친 것들입니다.

· 프롬프트를 돌리려면 본인 AI 계정이 필요하고, 사용한 만큼 종량제로 결제됩니다.
  이 금액에 포함되지 않습니다. 콘텐츠 1건당 수십 원 수준입니다.

· 결과물 검수는 사람이 해야 합니다. 자료에서도 사람 몫으로 남겨둔 단계입니다.

■ 분량에 대해

A4 14쪽입니다. 페이지 수로 파는 물건이 아닙니다. 실질 가치는 부록 A의 프롬프트에
있고, 본문은 그 프롬프트가 왜 그렇게 쓰였는지를 설명합니다. 목차를 위에 전부
공개해 두었으니 보시고 필요 없다 싶으면 구매하지 마십시오.
```

### 가격 패키지

크몽은 3단 패키지를 요구합니다. 전자책은 단일 상품이라 아래처럼 구성합니다.

| | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 이름 | 전자책 단품 | 전자책 + 니치 1종 맞춤 | 전자책 + 1:1 세팅 |
| 가격 | 29,000원 | 79,000원 | 「도구 판매가에 맞춰 결정」 |
| 내용 | PDF 전권 | PDF + 업종에 맞춘 프롬프트 1종 제작 | PDF + 자동화 도구 + 세팅 대행 |
| 작업일 | 즉시 | 2일 | 3일 |

DELUXE 이상은 실제로 작업이 들어가므로, **동시에 소화 가능한 건수를 넘겨 받지
마십시오.** 납기 못 지키면 크몽 지표가 깎입니다.

### 수정 및 환불 규정

```
· 전자책(STANDARD)은 파일 전달 즉시 열람이 가능하여, 전달 후 단순 변심에 의한
  환불은 어렵습니다. 목차와 본문 발췌를 상세페이지에 전부 공개해 두었으니
  구매 전 확인 부탁드립니다.
· 파일이 열리지 않거나 내용이 설명과 다른 경우 전액 환불해 드립니다.
· DELUXE 이상은 작업 착수 전까지 전액 환불 가능하며, 착수 후에는 진행률에 따라
  협의합니다.
· 맞춤 프롬프트 제작은 2회까지 수정해 드립니다.
```

## 2. 스마트스토어

디지털 콘텐츠는 **자동 발송(파일 다운로드)** 상품으로 등록합니다.

### 상품명

```
인스타 카드뉴스 다국어 발행 실전 가이드 + 복붙 프롬프트 팩 (PDF)
```

### 상세페이지

위 크몽 「서비스 설명」을 그대로 쓰되, 맨 위에 아래 문단을 추가합니다.

```
※ 본 상품은 PDF 파일입니다. 결제 후 다운로드 링크가 자동 발송됩니다.
※ 조회수·팔로워·수익을 보장하지 않습니다. 콘텐츠 제작 시간 단축을 위한 자료입니다.
```

### 필수 고지

스마트스토어는 통신판매업 신고가 필요합니다. 그리고 디지털 콘텐츠는
**청약철회 제한 사유**를 상품 정보에 명시해야 합니다.

```
[청약철회 제한] 전자적 형태의 콘텐츠로, 다운로드가 시작된 이후에는
전자상거래법 제17조 제2항에 따라 청약철회가 제한될 수 있습니다.
다운로드 전에는 언제든 청약철회가 가능합니다.
```

> 위 문구는 일반적인 예시입니다. **실제 표기는 스마트스토어 안내와 관련 법령을
> 직접 확인해서 쓰십시오.** 법률 자문이 아닙니다.

## 3. 자체 판매 (계좌이체 · 토스)

수수료가 0원이고 정산이 즉시라 가장 빠릅니다. 대신 신뢰 장치를 직접 만들어야 합니다.

### DM 응대 순서

1. 판매 페이지 링크를 보냅니다 (`ebook/sales.html` 를 호스팅한 주소)
2. 입금 안내 — 계좌 또는 토스 링크
3. 입금 확인 후 다운로드 링크 전달
4. 현금영수증 발행 여부 확인

### 입금 안내 문구

```
전자책 「기사 하나로 콘텐츠 20개」 29,000원입니다.

「은행 / 계좌번호 / 예금주」

입금하시고 성함 남겨주시면 다운로드 링크 보내드리겠습니다.
현금영수증 필요하시면 휴대폰 번호 같이 주세요.

혹시 목차 아직 안 보셨으면 여기서 먼저 확인하세요 — 「판매 페이지 링크」
보시고 필요 없다 싶으면 안 사셔도 됩니다.
```

마지막 두 줄을 빼지 마십시오. **사지 말라고 하는 판매자가 더 잘 팔립니다.**

### 전달 문구

```
입금 확인했습니다. 감사합니다.

다운로드: 「링크」

프롬프트는 부록 A에 있습니다. 소재와 언어 자리만 바꾸시면 바로 돌아갑니다.
쓰시다가 막히는 부분 있으면 편하게 물어보세요.

업데이트하면 이 링크로 그대로 반영됩니다.
```

## 4. 파일 전달 방법

| 방법 | 장점 | 주의 |
|---|---|---|
| **구글 드라이브 링크** | 즉시, 무료, 업데이트 반영 | 링크 공유 설정을 "링크가 있는 모든 사용자"로 |
| 크몽 첨부 | 자동, 유출 추적 가능 | 크몽 결제분만 |
| 메일 첨부 | 확실함 | 용량 제한, 업데이트 재발송 필요 |

**구매자별로 링크를 따로 만들 필요는 없습니다.** 29,000원짜리에 그 관리 비용을
쓰는 건 남는 장사가 아닙니다. 대신 **PDF에 구매자 이름을 넣는 것**은 유출 억제에
효과가 있으니, 판매량이 늘면 그때 도입하십시오.

업데이트를 약속했으므로 **같은 링크에 파일을 덮어쓰는 방식**이 관리하기 편합니다.
구글 드라이브는 "버전 관리 > 새 버전 업로드"로 링크를 유지한 채 교체됩니다.

## 5. 세금

전자책 판매도 소득입니다.

- 사업자가 있으면 부가세 10%를 판매가에 포함할지 별도로 받을지 **미리 정하십시오.**
  나중에 정하면 10%를 그냥 잃습니다.
- 사업자가 없으면 기타소득 또는 사업소득으로 종합소득세 신고 대상입니다.
- 스마트스토어는 통신판매업 신고가 필요합니다.

> 세무는 전문가 확인을 받으십시오. 이 문서는 참고용입니다.
