# 판매 채널 등록 문안

크몽·스마트스토어·자체 판매에 그대로 붙여넣는 문구입니다.
`「」` 자리만 채우면 됩니다.

> **전 채널 공통 원칙**
> 수익·조회수·팔로워를 보장하는 문구는 어디에도 쓰지 않습니다. 표시광고법 위반
> 소지가 있고, 분쟁이 나면 전액 환불 대상이 됩니다. 파는 건 **제작 시간**입니다.

## 0. 먼저 — 돈을 어떻게 받을 것인가

이게 채널 선택을 결정합니다. **핵심은 사업자등록이 앞에 걸리느냐입니다.**

| 방법 | 사업자등록 | 열리는 데 걸리는 시간 | 수수료 | 파일 전달 |
|---|---|---|---|---|
| **계좌이체 · 토스 송금링크** | 불필요 | **즉시** | 0원 | 수동 |
| **크몽** | 불필요 (개인도 활동 가능) | 심사 1~3영업일 | 판매 누적액 따라 차등 (구간별 약 15% → 8% → 3%) | **크몽이 자동 처리** |
| **아임웹 등 디지털 상품 지원 자체몰** | **필요** | 사업자 체인 + 쇼핑몰 세팅 | 플랫폼 수수료 없음 (PG 수수료·요금제 별도) | **자동 다운로드** |
| PG 결제링크만 (토스페이먼츠 등) | **필요** | 사업자등록 → 통신판매업 신고 → 심사 | 약 3% | **수동** (직접 붙이면 자동) |
| 스마트스토어 | **필요** | 위와 같은 체인 | 약 3~6% | 수동 |

> 수수료율과 요금제는 바뀝니다. **계약 전에 각 사 공식 안내에서 직접 확인하십시오.**

### PG는 결제만 합니다 — 자동 발송과 다릅니다

여기서 자주 헷갈립니다. **토스페이먼츠 같은 PG는 결제를 처리할 뿐, 파일을 보내지
않습니다.** 자동 발송을 하려면 결제 완료 신호를 받아서 파일을 내주는 무언가가
따로 있어야 합니다.

```
[결제] 토스페이먼츠  →  ??? 여기가 비어 있음  →  [파일 전달]
```

그 빈칸을 채우는 방법은 셋입니다.

| 방법 | 무엇이 필요한가 | 현실성 |
|---|---|---|
| **자체몰에 디지털 상품 기능** (아임웹 등) | 쇼핑몰 세팅. PG를 결제 수단으로 연결 | **가장 무난함** |
| **마켓플레이스** (크몽) | 없음 — 결제·전달 모두 대행 | 가장 빠름 |
| **직접 개발** | 결제 성공 웹훅 → 다운로드 링크 발급 서버 | 29,000원 상품에 과함 |

**PG만 붙이고 자동 발송을 기대하면 안 됩니다.** 결제는 되는데 파일은 여전히
사람이 보내야 합니다.

### PG 결제링크가 왜 바로 안 되는가

토스페이먼츠 같은 PG로 결제링크를 만들려면 **사업자등록번호가 필요하고**,
판매 페이지에 상호·대표자명·사업자등록번호·주소·연락처·통신판매업 신고번호를
표기해야 합니다. 그리고 통신판매업 신고를 하려면 사업자번호가 먼저 있어야 합니다.

```
사업자등록 (홈택스, 온라인)
   ↓
통신판매업 신고 (정부24, 면허세)
   ↓
PG 가맹 심사
   ↓
결제링크 발급
```

토스페이먼츠는 사업자등록 간이신청을 자체 제공하니 시작점으로 쓸 만합니다.
다만 **이 체인 전체가 72시간 안에 끝난다고 가정하고 계획을 세우지는 마십시오.**

### 그래서 72시간 기준 권장

> **사업자등록번호 237-27-01200 (개인사업자) 보유.**
> 사업자등록 단계는 건너뜁니다. 남은 관문은 **통신판매업 신고** 하나입니다.

1. **계좌이체로 지금 시작합니다.** 수수료 0원, 정산 즉시, 오늘 팔 수 있습니다.
   사업자가 있으니 **현금영수증·세금계산서 발행이 가능**하고, 이건 개인 판매자보다
   확실한 신뢰 요소입니다. 판매 페이지에 사업자 정보를 적어두십시오.
2. **크몽을 동시에 신청합니다.** 심사 기다리는 동안 1번으로 팝니다.
   에스크로라 신뢰도가 높고 **결제와 파일 전달을 모두 크몽이 대신합니다.**
3. **통신판매업 신고를 지금 넣습니다.** 정부24에서 온라인 신청하고 면허세가 붙습니다.
   이게 나와야 아임웹·스마트스토어·PG를 엽니다. **사업자등록보다 훨씬 빠릅니다.**
4. **신고번호 나오면 아임웹으로 옮깁니다.** 자동 발송의 최종 목적지입니다 —
   수수료도 제일 낮고 구매자 명단도 내 것이 됩니다.

### 사업자가 있으면 추가로 열리는 것

| | 개인 | 사업자 (지금) |
|---|---|---|

> 10%를 그냥 잃습니다. 간이과세자냐 일반과세자냐에 따라 처리가 다르니
> 세무 확인을 받으십시오.

`sell/PLAYBOOK.md` 2-1에 "사업자가 없으면 Studio 티어의 최대 걸림돌"이라고 적어둔
항목은 이제 해소됐습니다. 대행사·법인 대상 149만원 제안이 가능해집니다.

**초기 판매량에서는 수동 발송이 문제가 안 됩니다.** 하루 몇 건이면 링크 복사해서
보내는 데 1분입니다. 자동화는 그게 귀찮아지는 시점에 붙이는 것이지, 첫 매출을
막으면서까지 먼저 만들 것이 아닙니다.

계좌이체가 초라해 보일 수 있는데, 29,000원짜리 디지털 상품에서는
**결제 수단보다 판매 페이지의 신뢰도가 훨씬 크게 작용합니다.**
목차와 발췌를 전부 공개해 둔 이유가 그것입니다.

## 2. 스마트스토어

**됩니다. 다만 72시간 안에 여는 채널로는 부적합합니다.** 두 가지가 걸립니다.

### 걸림돌 1 — 파일 자동 발송 기능이 없습니다

스마트스토어에는 결제 후 파일을 자동으로 내려주는 기능이 없습니다.
전자책 판매자들은 아래 중 하나를 씁니다.

| 방법 | 실제 운영 |
|---|---|
| **수동 발송** | 주문 확인하고 구매자 연락처로 링크를 직접 보냄. 판매량 적을 땐 이게 제일 낫습니다 |
| 외부 자동화 | 스티비·채널톡 등 메일 자동발송 도구를 붙임. 세팅에 시간이 듭니다 |

즉 "결제하면 알아서 다운로드"가 아니라 **사람이 보내는 구조**를 전제하고
상세페이지를 써야 합니다. 발송 소요 시간을 반드시 명시하십시오.

### 걸림돌 2 — 사업자등록과 통신판매업 신고

스마트스토어 판매에는 사업자등록이 필요하고, 통신판매업 신고를 하려면
사업자번호가 먼저 있어야 합니다. 순서가 이렇게 걸립니다.

```
사업자등록 (홈택스, 온라인)  →  통신판매업 신고 (정부24, 면허세 있음)  →  스토어 개설
```

> 통신판매업 신고에는 면제 대상이 있습니다(거래 횟수·과세 유형 기준).
> 기준이 바뀌므로 **정부24와 공정거래위원회 안내에서 직접 확인하십시오.**
> 이 문서는 법률 자문이 아닙니다.

**72시간 안에 첫 매출을 노린다면 스마트스토어는 뒤로 미루십시오.**
아래 3번 자체 판매로 시작하고, 스마트스토어는 사업자등록이 나온 뒤에 엽니다.

```
인스타 카드뉴스 다국어 발행 실전 가이드 + 복붙 프롬프트 팩 (PDF)
```

```
※ 본 상품은 PDF 파일입니다. 결제 확인 후 「○시간」 이내에 주문서에 남겨주신
   연락처로 다운로드 링크를 보내드립니다. (자동 발송이 아닙니다)
※ 주문 시 링크를 받으실 이메일 또는 연락처를 반드시 남겨주세요.
※ 조회수·팔로워·수익을 보장하지 않습니다. 콘텐츠 제작 시간 단축을 위한 자료입니다.
```

**"자동 발송"이라고 쓰지 마십시오.** 실제로는 사람이 보내는데 자동이라고 적으면
구매자가 결제 직후 파일을 기다리다 클레임을 겁니다. 소요 시간을 적고 그 안에
보내는 쪽이 분쟁이 없습니다.

### 필수 고지

스마트스토어는 통신판매업 신고가 필요합니다. 그리고 디지털 콘텐츠는
**청약철회 제한 사유**를 상품 정보에 명시해야 합니다.

```
[청약철회 제한] 전자적 형태의 콘텐츠로, 다운로드가 시작된 이후에는
전자상거래법 제17조 제2항에 따라 청약철회가 제한될 수 있습니다.
다운로드 전에는 언제든 청약철회가 가능합니다.
```

> 위 문구는 일반적인 예시입니다. **실제 표기는 스마트스토어 안내와 관련 법령을
> 직접 확인해서 쓰십시오.** 법률 자문이 아닙니다.

## 3. 자체 판매 (계좌이체 · 토스)

수수료가 0원이고 정산이 즉시라 가장 빠릅니다. 대신 신뢰 장치를 직접 만들어야 합니다.

### DM 응대 순서

1. 판매 페이지 링크를 보냅니다 (`ebook/sales.html` 를 호스팅한 주소)
2. 입금 안내 — 계좌 또는 토스 링크
3. 입금 확인 후 다운로드 링크 전달
4. 현금영수증 발행 여부 확인

### 입금 안내 문구

```
전자책 「기사 하나로 콘텐츠 20개」 29,000원입니다.

「은행 / 계좌번호 / 예금주」

입금하시고 성함 남겨주시면 다운로드 링크 보내드리겠습니다.
현금영수증 필요하시면 휴대폰 번호 같이 주세요.

혹시 목차 아직 안 보셨으면 여기서 먼저 확인하세요 — 「판매 페이지 링크」
보시고 필요 없다 싶으면 안 사셔도 됩니다.
```

마지막 두 줄을 빼지 마십시오. **사지 말라고 하는 판매자가 더 잘 팔립니다.**

### 전달 문구

```
입금 확인했습니다. 감사합니다.

다운로드: 「링크」

프롬프트는 부록 A에 있습니다. 소재와 언어 자리만 바꾸시면 바로 돌아갑니다.
쓰시다가 막히는 부분 있으면 편하게 물어보세요.

업데이트하면 이 링크로 그대로 반영됩니다.
```

## 4. 파일 전달 방법

| 방법 | 장점 | 주의 |
|---|---|---|
| **구글 드라이브 링크** | 즉시, 무료, 업데이트 반영 | 링크 공유 설정을 "링크가 있는 모든 사용자"로 |
| 크몽 첨부 | 자동, 유출 추적 가능 | 크몽 결제분만 |
| 메일 첨부 | 확실함 | 용량 제한, 업데이트 재발송 필요 |

**구매자별로 링크를 따로 만들 필요는 없습니다.** 29,000원짜리에 그 관리 비용을
쓰는 건 남는 장사가 아닙니다. 대신 **PDF에 구매자 이름을 넣는 것**은 유출 억제에
효과가 있으니, 판매량이 늘면 그때 도입하십시오.

업데이트를 약속했으므로 **같은 링크에 파일을 덮어쓰는 방식**이 관리하기 편합니다.
구글 드라이브는 "버전 관리 > 새 버전 업로드"로 링크를 유지한 채 교체됩니다.

## 5. 세금

전자책 판매도 소득입니다.

- 사업자가 있으면 부가세 10%를 판매가에 포함할지 별도로 받을지 **미리 정하십시오.**
  나중에 정하면 10%를 그냥 잃습니다.
- 사업자가 없으면 기타소득 또는 사업소득으로 종합소득세 신고 대상입니다.
- 스마트스토어는 통신판매업 신고가 필요합니다.

> 세무는 전문가 확인을 받으십시오. 이 문서는 참고용입니다.
