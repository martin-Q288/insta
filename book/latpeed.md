# 래피드 등록 문안

`book/ebook.pdf` 를 래피드(latpeed)에 올릴 때 그대로 복사해 쓰는 문서다.
대괄호만 본인 값으로 바꾸면 된다.

---

## 0. 등록 전 확인

| 항목 | 값 |
|---|---|
| 파일 | `book/ebook.pdf` (22면) |
| 수수료 | 1.6% |
| 사업자등록 | 불필요 (있으면 정산·세금계산서에서 유리) |
| 자동 발송 | 결제 즉시 |
| 무료 미리보기 | 앞 3면 |

**미리보기 3면이 그대로 판매 문구 역할을 한다.** 1면 표지, 2면은 수익을
보장하지 않는다는 고지와 1장 도입부다. 이 순서를 흐트러뜨리지 마라 —
"안 판다"는 말로 시작하는 미리보기가 후기 0개를 가장 잘 덮는다.

**올리기 전에 파일이 실제로 첨부됐는지 확인하고, 다른 결제수단으로
본인이 한 건 사봐라.** 이 두 가지를 안 하고 판매를 여는 사고가 가장 흔하다.

## 2. 가격 정책

**시작가 29,000원 · 30권 한정 · 한 권 팔릴 때마다 1,000원 인상.**

| | |
|---|---|
| 첫 권 | 29,000원 |
| 30권째 | 58,000원 |
| 완판 시 합계 | 1,305,000원 |
| 수수료 1.6% 제외 | 약 1,284,000원 |

### 왜 이 숫자인가

**시작가를 3만원 아래로 둔 이유.** 지금 병목은 가격이 아니라 접촉량이다.
새 계정에 후기 0개면 5만원이든 3만원이든 안 보면 0원이고, 보이더라도
모르는 사람에게 5만원을 내는 문턱은 확실히 높다. 그러면 가격은 **첫
구매자를 최대한 많이 만드는 쪽**으로 잡는 게 맞다. 초기 구매자는 매출이
아니라 후기 공장이다.

그리고 인상 장치가 있으니 낮게 시작해도 손해가 아니다. 30권이 다 나가면
58,000원까지 오르고, 인상분만으로 435,000원이 붙는다.

**수량을 30권으로 줄인 이유.** 완판이 안 되면 중계가 죽는다. "완판"이라는
사건이 있어야 시즌2를 열 수 있고, 50권 미달보다 30권 완판이 낫다.
남으면 다음 판매에서 늘리면 된다. 줄이는 건 못 한다.

**참고 — 원본은 권당 10만원으로 시작했다.** 10권 100만원이었다. 다만 그쪽은
유튜브 채널, 오픈채팅방, 스레드를 이미 갖고 있었다. 오디언스 없이 그
가격표를 그대로 쓰면 안 된다.

### 지킬 것

**규칙은 반드시 지켜라.** 30권이라고 했으면 30권에서 닫는다. 잘 팔린다고
늘리는 순간 다음 판매 때 아무도 안 믿는다. 신뢰가 가격 정책보다 비싸다.

그리고 **현재 가격을 계속 노출해라.** 올라가는 게 안 보이면 그냥 정찰제다.

> 완판해도 130만원이다. 500만원은 이 한 권으로 안 된다.
> 원본이 500만원을 넘긴 경로는 시즌1을 완판한 뒤 **그 완판 과정 자체를 담은
> 두 번째 책**을 더 높은 가격에 건 것이다. 시즌1이 끝나면 우리에게도
> 지어낼 필요 없는 실제 기록이 생긴다. 고가는 그때 건다.
>
> 지금 없는 실적으로 고가를 거는 건 허위고, 표시광고법 문제가 된다.

## 3. 상세페이지

### 3-1. 후킹 (맨 위)

```
AI 구독료는 매달 나갑니다.
그런데 AI로 번 돈은 아직 0원입니다.

만들 줄 몰라서가 아닙니다.
랜딩페이지도 만들어봤고, 자동화도 돌려봤고, PDF도 한 권 뽑아봤습니다.

그런데 그중에 돈을 받아본 건 몇 개입니까.
```

### 3-2. 문제

```
만드는 것과 파는 것 사이에는 여섯 칸이 있습니다.

  ① 뭘 팔지  ② 어디서  ③ 어떻게 전달  ④ 법  ⑤ 신뢰  ⑥ 유통

대부분의 자료는 만드는 법에서 끝납니다.
그래서 이 여섯 칸이 있다는 것조차 모른 채 각 칸에서 멈춥니다.

어려워서가 아니라, 거기 칸이 있는 줄 몰라서 멈춥니다.
```

### 3-3. 이 자료가 다루는 것

```
· 플랫폼 네 종류의 성격 차이 — PG / 마켓플레이스 / 오픈마켓 / 스토어프론트
  어디는 손님이 있고 어디는 자동발송이 되는지, 표로 정리

· 결제와 전달은 다른 문제다
  결제를 붙였다고 팔 준비가 된 게 아닌 이유

· 통신판매업 신고와 사업자등록
  언제 필요하고 언제 면제되는지, 신고번호를 어디서 확인하는지

· 환불 규정 쓰는 법
  "채널 정책을 따릅니다"가 왜 위험한지, 전달 전/후/하자를 나누는 문안 그대로

· 수익 보장 문구가 왜 전액 환불로 돌아오는지

· 후기가 0개일 때 그것을 대체하는 다섯 가지

· 판매 과정 자체를 콘텐츠로 돌리는 법
  안 팔리는 것조차 쓸 거리가 되는 구조

· 한정 수량과 건당 인상 가격 정책

부록 A — 복붙 프롬프트 7종
  팔 것 정하기 / 원고 쓰기 / 상세페이지 / 환불 규정 /
  판매 중계 글 / 상담 답변 / 출시 전 점검

부록 B — 출시 체크리스트 (인쇄용)
부록 C — 수치 확인 시점과 확인 방법 (요율은 바뀐다)
```

### 3-4. 다루지 않는 것 (반드시 넣을 것)

```
이 자료가 하지 않는 것도 적어둡니다.

· 수익 금액을 약속하지 않습니다. 얼마를 번다, 며칠이면 본전,
  이런 말은 한 줄도 없습니다
· 매출 스크린샷이 없습니다. AI로 만든 걸 팔아서 벌었다는 실적이 아직 없습니다
· 코딩을 가르치지 않습니다. 만드는 건 이미 하실 줄 안다는 전제입니다
· 법률·세무 자문이 아닙니다. 실무에서 통용되는 정리이고,
  규모가 커지면 전문가 확인이 필요합니다
```

### 3-5. 실적 고지

```
AI로 만든 걸 팔아서 얼마를 벌었다는 실적은 없습니다.

다만 파는 것 자체가 처음은 아닙니다.
공동구매 중개를 해왔고, 통신판매업 신고는 2021년에 했고,
스마트스토어를 지금도 돌리고 있습니다.
결제, 정산, 전달, CS, 환불 분쟁은 겪을 만큼 겪었습니다.

그런데 AI로 만든 걸 팔려니까 그중 상당수가 안 통했습니다.
물건이 실물이 아니라 파일이라는 것 하나 때문에
플랫폼 선택부터 환불 규정까지 전부 달라집니다.

이 자료는 그 차이를 정리한 것입니다.
틀렸던 것도 그대로 적었습니다.
완벽한 결과물은 누구나 꾸며낼 수 있지만,
실패의 구체성은 겪은 사람만 씁니다.

앞 3면을 무료로 보실 수 있습니다. 읽어보시고 판단하십시오.
```

> **이 문단이 이 페이지에서 가장 중요하다.** 후기가 0개일 때 그것을 대신하는
> 게 검증 가능한 사실인데, 사업자등록·통신판매업 신고·운영 중인 스토어는
> 전부 열어보면 확인된다. 조작이 안 되는 근거다.
>
> 다만 **AI 상품 실적과 판매 경력을 섞지 마라.** 앞의 것은 없고 뒤의 것은
> 있다. 그 구분을 흐리는 순간 과장이 되고, 하나가 걸리면 나머지도 의심받는다.

## 4. 환불 규정 (그대로 복사)

```
[전달 전]
파일이나 다운로드 링크를 보내드리기 전이면 전액 환불됩니다.

[전달 후]
파일을 받으신 뒤에는 청약철회가 제한됩니다. 디지털 파일은 전달 즉시
복제가 가능하기 때문이며, 이 안내가 전자상거래법 제17조 제2항 제5호가
요구하는 사전 고지입니다.

[하자]
파일이 열리지 않거나 상세페이지 설명과 다른 경우는 하자이므로
환불 대상입니다.

[미리보기]
구매 전에 앞 3면을 무료로 확인하실 수 있습니다.
```

**플랫폼 약관을 그대로 옮기지 마라.** 판매자에게 적용되는 조항과 구매자에게
적용되는 조항이 섞여 있다. 원본을 읽고 누구에게 적용되는지 확인한 뒤 옮겨라.
원본 사례에서 AI가 플랫폼의 "판매자는 3일 이내 취소 가능"을 구매자 환불
조건으로 잘못 읽고 상세페이지에 옮겨 적은 일이 있었다.

## 6. 등록 순서

1. 래피드 가입 (사업자등록 없이 됨, 30분 안팎)
2. 상품 등록 — 위 1~3 문안 붙여넣기
3. **`book/ebook.pdf` 첨부 확인**
4. 미리보기 3면 설정
5. 가격 29,000원, 수량 30 설정
6. 환불 규정 붙여넣기 (4번)
7. 판매자 정보 입력 (5번)
8. **다른 결제수단으로 본인이 한 건 구매 → 메일 수신·파일 열림 확인**
9. 판매 링크 확보 → `threads/config.json` 의 상품 링크에 반영
10. 스레드 중계 시작 (`threads/README.md`)

9번까지 끝나기 전에 10번으로 가지 마라. 링크 없는 홍보 글은 한 번 나가면
주워담을 수 없고, 새 계정에서는 그 한 번이 크다.
