# AI 활용할 줄은 아는데 어떻게 수익화 할까

판매 가능한 아이템 목록부터 견적·응대·입금까지

---

## 이 자료의 대상

**ChatGPT나 클로드에 질문을 해본 적이 있으면 대상입니다.**

기준을 이렇게까지 낮추는 이유가 있습니다. 시장에서 실제로 돈이 오가는 작업 상당수가
**높은 기술을 요구하지 않기 때문입니다.** 5만원짜리 엑셀 자동화가 꾸준히 거래되는 건
그 업무가 지겨운 사람이 많아서지, 그 코드가 어려워서가 아닙니다.
그리고 그 코드는 지금 AI가 대신 씁니다.

필요한 것은 셋뿐입니다.

- AI에게 질문하고 결과를 확인할 수 있다
- 엑셀이나 구글 시트를 열어본 적 있다
- 모르는 게 나오면 검색해서 30분 정도는 붙들 수 있다

**코딩은 몰라도 됩니다.** 이 자료의 3장에 난이도별 아이템 목록이 있고,
난이도 1은 코드가 한 줄도 안 들어갑니다.

### 다루는 것과 다루지 않는 것

| 다루는 것 | 다루지 않는 것 |
|---|---|
| 수익 모델 4종과 실제 시장 단가 | AI 도구 기초 사용법 |
| **판매 가능한 아이템 30여 개 — 난이도·가격대별** | 코딩 교육 |
| **난이도별 제작 방법과 사용 도구** | 유료 광고 집행 |
| 아이템 검증 · **3단 구성(패키지) 설계** | 법률·세무 자문 (실무 정리까지) |
| 견적 산정과 범위 합의 | |
| **문의 응대 실제 대화 스크립트와 이의 처리** | |
| 리드 확보 · 가격 정책 · 레퍼런스 0 대응 | |
| 결제 채널 · 납품 · 법무 | |
| **7일 실행 캘린더** | |

수치는 확인해서 넣었으며, 확인 경로를 부록 C에 함께 적었습니다.

## 1. 수익 모델 4종

AI 수익화는 다양해 보이지만 구조는 넷입니다. 넷은 **서로 다른 사업**입니다.

### ① 제품 판매

전자책, 템플릿, 프롬프트 팩, 노션 서식, GPTs. 한 번 만들어 반복 판매합니다.

- **객단가** 5천~5만원대 (크몽 최저 등록가 5,000원)
- **리드타임** 며칠
- **확장** 수량. 판매가 늘어도 원가가 거의 안 늡니다
- **병목** **트래픽.** 3만원 상품으로 300만원을 만들려면 100건이고,
  유입 없이 100건은 나오지 않습니다

### ② 제작 대행

클라이언트 업무를 자동화하거나 도구를 만들어 줍니다.

- **객단가** 업무 자동화·매크로가 **평균 20만원 수준**.
  단순 엑셀 자동화 15만원부터, 파이썬 데이터 수집이나 API 연동이 붙으면
  **30만~100만원대**, 예외 처리와 다중 시스템 연동이 들어가면 **200만원대**
- 챗봇은 구간이 다릅니다 — 룰 기반 300만~1,000만원대
- **리드타임** 1~3주
- **확장** 객단가와 가동 시간
- **병목** **내 공수.** 가동을 멈추면 매출도 멈춥니다

### ③ 운영 대행 · 구독

구축에서 끝내지 않고 매월 운영합니다.

- **객단가** 월 과금. LLM API를 태우는 서비스는 운영비만 **월 30만~200만원**
  규모가 잡히고, 여기에 운영 마진이 붙습니다
- **리드타임** 1개월 이상
- **확장** **누적.** 이번 달 계약이 다음 달에도 살아 있습니다
- **병목** 판매 난이도. 매월 고정비를 승인하는 결재라 문턱이 높습니다

### ④ 교육 · 컨설팅

- **객단가** 편차가 큽니다
- **리드타임** 가장 깁니다
- **병목** **레퍼런스.** 실적 없이는 시작 자체가 안 됩니다

### 비교표

| | 객단가 | 리드타임 | 확장 | 병목 |
|---|---|---|---|---|
| ① 제품 | 5천~5만원 | **며칠** | 수량 | 트래픽 |
| ② 제작 대행 | 15만~200만원 | 1~3주 | 가동 시간 | 내 공수 |
| ③ 운영 대행 | 월 과금 | 1개월+ | **누적** | 판매 난이도 |
| ④ 교육 | 편차 큼 | 가장 김 | 가동 시간 | 레퍼런스 |

> 2026년 7월 확인 기준. 확인 경로는 부록 C.

## 2. 어떤 모델로 시작할 것인가

①번이 가장 매력적으로 보입니다. 자동으로 매출이 나니까요.
그런데 ①번은 **트래픽이 없으면 0원입니다.**

### 판단 축은 두 개

| | 오디언스 있음 | 오디언스 없음 |
|---|---|---|
| **자금 급함** | ① 제품 | **② 제작 대행** |
| **여유 있음** | ③ 운영 대행 | ② 로 시작해 ①③ 으로 확장 |

**오디언스가 없고 자금이 급하면 ②번입니다.** 건당 15만~100만원이므로
몇 건이면 목표에 닿습니다. 같은 금액을 ①번으로 만들려면 수십 건이 필요합니다.

> **오디언스가 없을 때는 소수에게 고단가로 파는 쪽이 먼저입니다.**

②번은 매출 외에 세 가지를 남깁니다 — **레퍼런스**, **실제 페인포인트 데이터**,
**가격 감각**. 이 셋이 ①③번의 재료입니다.

**다만 ②번에 머무르면 안 됩니다.** 같은 요청이 세 번 들어오면 제품화(①) 또는
구독화(③) 신호입니다.

이 자료의 3장부터는 **②번 기준**으로 씁니다. 시작점으로 가장 현실적이기 때문입니다.
①번으로 갈 분은 7장(가격 정책)과 9장(결제 채널)을 먼저 보십시오.

## 3. 판매 가능한 아이템 — 난이도별 30선

여기가 이 자료의 핵심입니다. **"반복 업무를 찾으세요"만으로는 아무것도 못 합니다.**
실제 목록이 필요합니다.

가격은 시장에서 관찰되는 구간이며, 본인 공수와 범위에 따라 달라집니다.

### 난이도 1 — 코드 없음 (AI 결과물을 정리해서 납품)

**필요한 것: ChatGPT 또는 클로드 계정 하나. 그게 전부입니다.**

| 아이템 | 참고 가격대 | 작업 시간 |
|---|---|---|
| 엑셀 함수·수식 문제 해결 | 3만~10만원 | 1~3시간 |
| 업무용 문서 양식 제작 (견적서·거래명세서·보고서) | 5만~15만원 | 반나절 |
| 상세페이지·블로그 원고 작성 | 건당 3만~10만원 | 2~4시간 |
| 상품명·키워드 세트 정리 | 5만~15만원 | 2~4시간 |
| 회의록·녹취 정리 규격화 | 건당 3만~8만원 | 1~2시간 |
| 고객 문의 응대 템플릿 세트 | 10만~30만원 | 반나절~1일 |
| 사내 FAQ 챗봇 (GPTs 등 노코드) | 15만~50만원 | 1~2일 |
| 업무별 프롬프트 세트 + 사용 가이드 | 10만~30만원 | 1일 |
| 이메일·공문 템플릿 라이브러리 | 10만~25만원 | 반나절 |
| 채용 공고·직무기술서 작성 | 5만~15만원 | 2~4시간 |

**난이도 1의 본질은 이겁니다.** 클라이언트도 ChatGPT를 쓸 수 있습니다.
그런데 **어떻게 물어야 원하는 결과가 나오는지 모르고, 나온 결과를 업무에 쓸 수 있게
정리할 시간이 없습니다.** 그 두 가지가 지불 이유입니다.

**결과물을 그대로 넘기지 마십시오.** 검수하고, 형식을 통일하고, 사용법을 붙여서
넘기는 것까지가 상품입니다.

### 난이도 2 — 노코드 도구 (설정 위주)

**필요한 것: 구글 계정, 노코드 자동화 도구 하나.**

| 아이템 | 참고 가격대 | 작업 시간 |
|---|---|---|
| 구글 시트 업무 자동화 (수식·조건부 서식·데이터 검증) | 10만~30만원 | 1일 |
| 폼 응답 → 시트 정리 → 자동 회신 메일 | 15만~40만원 | 1~2일 |
| 신규 주문·문의 발생 시 알림 연동 | 15만~40만원 | 1~2일 |
| 노션 업무 데이터베이스 설계 | 20만~60만원 | 2~3일 |
| 정기 리포트 자동 생성·발송 | 30만~80만원 | 2~4일 |
| 재고·주문 대조 자동화 (시트 기반) | 20만~50만원 | 2~3일 |
| 명함·영수증 이미지 → 데이터 정리 | 20만~50만원 | 2~3일 |
| SNS 게시물 예약 발행 세팅 | 15만~40만원 | 1~2일 |

**구글 시트의 Apps Script는 코드지만, 그 코드를 AI가 씁니다.**
필요한 건 "무엇을 만들지 설명하는 능력"과 "안 될 때 오류 메시지를 AI에게
그대로 붙여넣는 인내심"입니다.

### 난이도 3 — AI가 코드를 작성 (검증은 내가)

**필요한 것: 위 + 파이썬 실행 환경 또는 엑셀 VBA 편집기.**

| 아이템 | 참고 가격대 | 작업 시간 |
|---|---|---|
| 엑셀 VBA 매크로 (반복 입력·클릭 자동화) | **5만원부터** (크몽 등록가 기준) | 1~3일 |
| 웹 데이터 수집 — 단일 카테고리 | **5만원 안팎** | 1~2일 |
| 웹 데이터 수집 + 엑셀 도구 제공 | **10만원 안팎** | 2~4일 |
| 다중 카테고리 수집 + 맞춤 프로그램 | **30만원 안팎** | 1주 |
| 파일 일괄 정리·이름 변경·분류 | 15만~40만원 | 1~2일 |
| PDF 일괄 처리 (병합·추출·변환) | 15만~40만원 | 1~2일 |
| 여러 시스템 간 데이터 연동 (API) | 50만~150만원 | 1~2주 |
| 사내 업무 로직이 들어간 자동화 프로그램 | 100만~200만원 | 2~3주 |
| 챗봇 (룰 기반) | 300만원~ | 1개월+ |

### 어디서 시작할 것인가

**난이도 1에서 두세 건 하고 2로 넘어가십시오.**

이유는 기술이 아니라 **감각** 때문입니다. 첫 건에서 배우는 건 코드가 아니라
"클라이언트는 요구사항을 정확히 말하지 못한다"는 사실입니다.
그걸 5만원짜리에서 배우는 편이 100만원짜리에서 배우는 것보다 훨씬 쌉니다.

## 4. 3단 구성으로 묶기

여기서 매출이 크게 갈립니다. **같은 기술로도 구성에 따라 객단가가 6배 차이 납니다.**

시장에서 실제로 쓰이는 방식은 단일 가격이 아니라 **3단 패키지**입니다.
크롤링 서비스의 실제 구성을 보면 이렇습니다.

| 등급 | 가격 | 범위 |
|---|---|---|
| STANDARD | 5만원 | 특정 사이트 **한 카테고리** 데이터 수집 |
| DELUXE | 10만원 | 데이터 + **엑셀 프로그램 제공** |
| PREMIUM | 30만원 | **여러 카테고리** 수집 + 맞춤형 프로그램 |

엑셀 VBA 쪽도 같은 구조입니다.

| 등급 | 범위 |
|---|---|
| STANDARD | 함수·매크로만, 결과값 3개 이하, 폼·DB 연결 없음 |
| DELUXE | 입력·클릭 반복 자동화, 조건 5개 이하, DB 연결 포함 |
| PREMIUM | DELUXE 포함 + DB 연동·구축, 업무 로직 개발 |

### 이 구조가 하는 일

**하나. 하한선을 만듭니다.** 최저가 등급이 있으면 "일단 이거라도"가 가능합니다.

**둘. 상한선을 올립니다.** 3단이 없으면 대부분 최저가로 수렴합니다.
있으면 **절반 이상이 중간 등급을 고릅니다.**

**셋. 범위 협상을 대신합니다.** "이건 PREMIUM 범위입니다"는
거절이 아니라 안내입니다. 스코프 크립이 자동으로 차단됩니다.

### 내 아이템으로 3단 만드는 법

등급을 가르는 기준은 **품질이 아니라 범위**입니다.
"더 잘 해드립니다"가 아니라 "더 많이 해드립니다"여야 합니다.

가를 수 있는 축은 다섯 개입니다.

| 축 | 예시 |
|---|---|
| **수량** | 1개 카테고리 / 3개 / 무제한 |
| **조건 개수** | 단순 조건 / 5개 이하 / 제한 없음 |
| **산출물 형태** | 결과 데이터만 / 실행 파일까지 / 유지보수 포함 |
| **자동화 정도** | 수동 실행 / 버튼 클릭 / 스케줄 자동 |
| **수정 횟수** | 1회 / 3회 / 1개월 무제한 |

예를 들어 "회의록 정리"라면 이렇게 나눕니다.

```
STANDARD  5만원 — 녹취 파일 1건, 요약본 1종, 수정 1회
DELUXE   12만원 — 5건, 요약본 + 액션아이템 + 담당자 정리, 수정 3회
                   재사용 가능한 프롬프트 제공
PREMIUM  30만원 — 무제한(월), 자동 수집·정리 세팅,
                   양식 커스터마이징, 수정 무제한
```

**PREMIUM에 "월"이라는 단어가 들어간 것을 보십시오.** 여기가 ③번 모델로
넘어가는 다리입니다. 3단 구성 자체가 구독 전환 장치입니다.

## 5. 아이템을 고르고 검증하기

### 고르는 기준 세 개

**하나. 내가 이미 해본 적 있는 작업인가.**
없으면 첫 건에서 공수가 세 배로 뜁니다. 목록에서 **경험이 겹치는 것**부터 고르십시오.

**둘. 클라이언트가 그 업무에 쓰는 시간이 눈에 보이는가.**
"주 3시간"처럼 환산되는 업무가 팔립니다. 안 보이면 가치 설명이 어렵습니다.

**셋. 결과물을 화면으로 보여줄 수 있는가.**
보여줄 수 있으면 레퍼런스 0을 시연으로 덮을 수 있습니다.

### 시장 검증 — 지어낸 조사에 속지 않기

AI에게 시장 규모를 물으면 **그럴듯한 숫자를 생성합니다.** 검색 능력이 없는데
물으니 만들어내는 겁니다.

대신 이렇게 합니다.

1. 아이템 키워드를 **크몽·숨고·오투잡에 그대로 검색**합니다
2. 등록 서비스 **수, 가격 구간, 리뷰 수**를 봅니다
3. **리뷰가 달린 서비스가 있으면 시장은 실재합니다**
4. 등록은 많은데 리뷰가 전부 0이면 **공급만 있고 수요가 없는 카테고리**입니다

**리뷰 수가 가장 정직한 지표입니다.** 등록 수는 진입 장벽이 낮다는 뜻일 뿐입니다.

### 그리고 상위 서비스의 상세페이지를 읽으십시오

리뷰가 많은 서비스 3개를 열어 이것만 뽑아냅니다.

- 3단 구성을 **어떤 축으로** 갈랐는가
- **불포함 범위**를 어떻게 적었는가
- 리뷰에서 고객이 **무엇을 칭찬했는가** (그게 실제 구매 이유입니다)
- 리뷰에서 **무엇을 아쉬워했는가** (그게 내 차별점입니다)

이 30분이 시장조사의 전부입니다.

## 6. 만드는 방법 — 난이도별

### 공통 원칙

**AI에게 "만들어줘"라고 하지 마십시오. "이 조건으로 만들어줘"라고 해야 합니다.**

조건에 반드시 넣을 것 넷입니다.

1. **입력** — 무엇이 들어오는가 (파일 형식, 열 이름, 예시 데이터)
2. **출력** — 무엇이 나와야 하는가 (형식, 항목, 예시)
3. **환경** — 어디서 돌리는가 (엑셀 버전, 윈도우/맥, 파이썬 유무)
4. **예외** — 값이 비었을 때, 형식이 다를 때 어떻게 할 것인가

**4번을 빠뜨리면 납품 후에 반드시 연락이 옵니다.**

### 난이도 1 — 결과물 정리형

1. 클라이언트 실제 데이터를 **샘플로 받습니다** (개인정보는 지운 상태로)
2. AI에게 조건을 주고 결과를 만듭니다
3. **직접 검수합니다.** 이게 상품의 실체입니다
4. 형식을 통일하고 **사용 가이드 A4 한 장**을 붙입니다
5. 재사용 가능한 프롬프트를 함께 제공하면 DELUXE 등급이 됩니다

### 난이도 2 — 노코드 세팅형

1. 클라이언트 계정이 아니라 **내 계정에서 먼저 만듭니다**
2. 샘플 데이터로 끝까지 돌려봅니다
3. 옮길 때는 **화면 녹화**를 남깁니다. 나중에 문의가 오면 그 영상이 답변입니다
4. 권한 설정을 문서로 남깁니다 — 여기서 사고가 제일 많이 납니다

### 난이도 3 — 코드 생성형

1. AI에게 **작은 단위로** 시킵니다. 한 번에 전체를 시키면 디버깅이 불가능합니다
2. 오류가 나면 **메시지 전문을 그대로 붙여넣습니다.** 요약하지 마십시오
3. **본인 데이터로 세 번 이상 돌려봅니다.** 특히 빈 값, 중복, 형식 오류
4. 실행 방법을 **클릭 순서**로 적어 줍니다. "파이썬을 설치하고"로 시작하면
   클라이언트가 못 씁니다. 실행 파일로 묶거나 대신 세팅해 주는 것까지가 범위입니다

### 첫 포트폴리오는 내 문제로 만듭니다

클라이언트가 없어도 됩니다. **본인이 반복하는 업무를 하나 자동화하고
그 과정을 정리하면 그게 포트폴리오입니다.**

- 전/후 소요 시간
- 화면 캡처 또는 30초 영상
- 무엇을 입력하면 무엇이 나오는지

이게 있으면 레퍼런스 0이 아닙니다.

## 7. 견적 산정

### 계산 순서

**1단계. 공수를 시간으로 추정합니다.**
요건 정리, 제작, 테스트, 납품 설명, 수정 1회까지 포함합니다.
**테스트와 수정을 빼면 반드시 적자가 납니다.**

**2단계. 목표 시급을 곱합니다.** 초기에는 3만~5만원.
8시간 작업이면 24만~40만원입니다.

**3단계. 시장가와 대조합니다.** 자동화 평균 20만원, 주력 30만~100만원.
크게 벗어나면 범위를 과하게 잡았거나 공수를 과소평가한 것입니다.

**4단계. 추정 공수에 1.5를 곱합니다.**
예외 처리에서 반드시 시간이 샙니다. 낙관 편향은 경험으로 잘 안 고쳐지므로
계수로 처리합니다.

### 견적서 필수 항목 9개

| 항목 | 왜 |
|---|---|
| **포함 범위** | 기준선 |
| **불포함 범위** | **이 줄이 없으면 범위가 무한대가 된다** |
| 산출물 형태 | 데이터만인지, 실행 파일까지인지, 설치까지인지 |

- 규모가 크면 착수 30 / 중간 30 / 납품 40
- **초기 몇 건은 마켓플레이스를 경유하십시오.** 수수료를 내지만 플랫폼이
  에스크로 역할을 하므로 대금 사고가 없습니다

이유 없이 싸면 품질 신호로 읽히고, 이유가 있으면 호의로 읽힙니다.

## 8. 문의 응대 — 실제 대화

여기서 성사율이 갈립니다. 순서와 문장을 그대로 쓰셔도 됩니다.

### ① 첫 답장 — 견적을 내지 않습니다

정보 없는 견적은 반드시 틀리고, 한번 말한 금액은 올리기 어렵습니다.

> 안녕하세요. 문의 주셔서 감사합니다.
> 정확한 견적을 위해 몇 가지만 여쭙겠습니다.
>
> 1. 지금은 그 작업을 어떻게 처리하고 계신가요?
> 2. 한 번 하는 데 얼마나 걸리고, 얼마나 자주 하시나요?
> 3. 데이터는 어디에 있나요? (엑셀 파일, 웹사이트, 사내 시스템 등)
> 4. 결과물은 어떤 형태로 받으셔야 하나요?
> 5. 언제까지 필요하신가요?
>
> 가능하시면 샘플 파일을 하나 보내주시면 더 정확하게 답변드릴 수 있습니다.
> 개인정보가 있으면 지우고 보내주셔도 됩니다.

**2번이 핵심입니다.** 여기서 나온 시간이 곧 고객이 느끼는 가치입니다.

### ② 가치를 환산해서 되돌려줍니다

> 주 3시간이면 월 12시간, 연 144시간이네요.
> 이 작업을 자동화하면 실행 후 결과 확인까지 5분 안쪽으로 줄어듭니다.

**금액을 말하기 전에 이 문장을 넣으십시오.** 순서가 반대면 비싸게 들립니다.

### ③ 범위를 문장으로 확정하고 확인받습니다

> 정리하면 이렇습니다.
> A 사이트에서 상품명·가격·재고를 수집해서 엑셀로 정리하고,
> 버튼 하나로 다시 실행할 수 있게 만드는 것까지입니다.
> **B 사이트 수집과 자동 발주는 이번 범위에 포함하지 않습니다.**
> 맞을까요?

**이 확인 한 번이 분쟁의 대부분을 막습니다.**

### ④ 견적을 3단으로 제시합니다

단일 금액보다 3단이 성사율이 높습니다. 선택지가 "할까 말까"에서
"어느 것으로 할까"로 바뀌기 때문입니다.

### ⑤ 선금 입금 후 착수합니다

"먼저 좀 보여주시면"에 응하면 대부분 무상 작업으로 끝납니다.
대신 이렇게 답합니다.

> 착수 전에 보여드릴 수 있는 건 이전 작업 화면입니다. 지금 보내드리겠습니다.
> 이번 건은 선금 확인 후 시작하고, 절반 진행 시점에 중간 결과를 공유드립니다.

### ⑥ 중간 공유 1회

완성본을 한 번에 보여주면 방향이 어긋났을 때 전부 다시 해야 합니다.
절반 시점 공유가 가장 저렴한 보험입니다.

### ⑦ 납품 — 사용 가이드를 함께

A4 한 장이면 충분합니다. 없으면 문의가 무한정 들어옵니다.

### ⑧ 잔금 청구와 레퍼런스 요청

> 잘 쓰고 계신지 궁금합니다.
> 혹시 이번 작업을 사례로 소개해도 괜찮을까요?
> 회사명은 빼고 "○○업종 주문 정리 자동화" 정도로만 적겠습니다.

**회사명을 빼겠다고 먼저 말하는 것이 승낙률을 크게 올립니다.**

## 9. 이의 처리

문의가 와도 여기서 대부분 끊깁니다. 자주 나오는 넷입니다.

### "생각보다 비싸네요"

가격을 내리지 마십시오. **범위를 내립니다.**

> 예산에 맞추려면 범위를 조정하는 방법이 있습니다.
> STANDARD로 하시면 A까지만 포함해서 ○○원입니다.
> 쓰시다가 B가 필요해지면 그때 추가로 진행하셔도 됩니다.

**가격을 깎으면 다음 고객에게도 그 가격이 기준이 됩니다.**

### "다른 데는 더 싸던데요"

경쟁사를 깎지 마십시오. **범위 차이로 답합니다.**

> 그 견적에 테스트와 납품 후 수정이 포함돼 있는지 확인해 보시면 좋겠습니다.
> 제 견적에는 수정 3회와 사용 가이드가 들어가 있습니다.
> 범위가 같다면 가격을 맞춰드리는 게 맞습니다.

### "AI로 제가 직접 하면 되지 않나요"

**맞다고 인정하고 시작합니다.** 부정하면 신뢰를 잃습니다.

> 네, 가능합니다. 실제로 그렇게 하시는 분들도 많습니다.
> 다만 대부분 시간이 걸리는 지점은 만드는 게 아니라
> 예외 상황 처리와 검증입니다. 데이터가 비었을 때, 형식이 다를 때,
> 사이트 구조가 바뀌었을 때요.
> 그 부분까지 포함해서 드리는 게 이 견적입니다.

### "일단 검토해보고 연락드릴게요"

여기서 끝나는 게 대부분입니다. **다음 접점을 만들어 두십시오.**

> 네, 편하게 검토해 보세요.
> 혹시 도움이 될까 해서 비슷한 작업 예시 하나 보내드립니다.
> 다음 주 중에 한 번만 더 여쭤봐도 괜찮을까요?

**"한 번만 더"라고 명시하면 승낙률이 올라갑니다.** 그리고 한 번만 하십시오.

## 10. 리드는 어디서 오는가

### 객단가가 접근 방식을 결정합니다

| 객단가 | 접근 |
|---|---|
| 30만원 이상 | **1:1 제안 유효.** 상대가 비용 대비 효익을 계산할 수 있다 |
| 3만원 안팎 | **1:1 제안 무효.** 콘텐츠로 유입시켜야 한다 |

3만원짜리를 콜드 메시지로 파는 건 계산이 맞지 않습니다.
전환율 1%로 30건이면 3,000통이고, 그 볼륨은 스팸이며 계정 정지 사유입니다.

### 초기 3개 경로 — 이 순서로

**1. 마켓플레이스 등록 (당일)**
크몽·숨고·오투잡에 서비스를 등록합니다. **트래픽이 이미 있는 곳입니다.**
수수료를 내지만 초기에는 **수수료보다 첫 건이 중요합니다.**

등록 시 이것만 지키십시오.
- **3단 구성**으로 올립니다 (4장)
- 썸네일에 **결과물 화면**을 넣습니다. 로고나 텍스트만 있으면 안 눌립니다
- 상세페이지에 **불포함 범위**를 적습니다. 문의 질이 올라갑니다
- 최저 등급을 **부담 없는 가격**으로 둡니다

**2. 아는 사람 20명 (당일)**
낯선 사람 1,000명보다 아는 사람 20명이 낫습니다.
특히 **뭔가를 파는 사람**을 우선하십시오. 반복 업무가 확실히 있습니다.

**3. 공개 질문에 답하기 (지속)**
사람들이 이미 질문한 곳을 찾아 **링크 없이 답만 합니다.**
대부분의 커뮤니티가 홍보를 금지하고, 링크가 붙는 순간 답변이 광고로 읽힙니다.
링크는 프로필에 둡니다.

### 1:1 제안 문안

대상 선정이 문안보다 중요합니다. **반복 업무가 눈에 보이는 곳**을 고르십시오 —
주문·재고를 수기 관리하는 소매업, 정산을 엑셀로 하는 소규모 업체,
문의 응대에 시간을 쓰는 서비스업.

300자 이내, 구조는 넷입니다.

1. 상대가 반복하고 있을 업무 (추측이면 추측이라고 밝힙니다)
2. 자동화하면 어떻게 바뀌는지
3. 무엇을 만들 것인지 구체적으로
4. 금액과 기간

**절감액을 숫자로 단정하지 마십시오.** 확인되지 않은 수치는 신뢰를 깎고
과장 광고 소지도 있습니다.

## 11. 가격 정책

### 제품(①)은 정찰제로 두면 아무 일도 안 일어납니다

오늘도 3만원, 내일도 3만원이면 오늘 살 이유가 없고 내일이면 잊습니다.

**한정 수량 + 건당 인상**을 겁니다.

- **지금 살 이유**가 생기고
- **콘텐츠 소재**가 생기고 ("3건 나갔고 가격이 올랐습니다")
- **초기 구매자가 보상**받으므로 레퍼런스 요청이 자연스러워집니다

**규칙은 공표하고 지킵니다.** 30개라 했으면 30개에서 닫습니다.
반응이 좋다고 늘리면 다음 판매에서 신뢰를 잃습니다.

### 대행(②)은 레퍼런스 연동 인상

| 건수 | 가격 |
|---|---|
| 1~2건차 | 시장가 하단, 이유를 밝히고 |
| 3~5건차 | 시장가 |
| 이후 | 시장가 상단, 또는 업종 특화로 포지셔닝 |

**같은 작업을 반복하면 공수가 줄고 단가는 유지되므로 시급이 올라갑니다.**
그게 대행의 확장 경로입니다.

## 12. 레퍼런스가 0일 때

리뷰가 수행하는 기능은 하나입니다 — **"이 사람 말이 사실인가"를 대신 검증**하는 것.
그 기능을 하는 다른 수단이 있으면 됩니다.

**하나. 자가 적용 포트폴리오.** 본인 업무를 자동화한 전/후 기록.
6장에서 만든 그것입니다.

**둘. 실시간 시연.** 상대가 준 데이터로 즉석에서 돌려 보입니다.
**위조가 불가능합니다.** 리뷰는 조작할 수 있지만 눈앞의 실행은 못 꾸밉니다.

**셋. 무상 파일럿.** 범위를 아주 작게 잘라 한 조각만 무상으로 합니다.
**전체가 아니라 2시간짜리 한 조각입니다.** 결과가 곧 레퍼런스가 됩니다.

**넷. 검증 가능한 사실.** 상대가 직접 확인할 수 있는 정보를 제시합니다.

**다섯. 인접 경력.** AI 관련 실적이 없어도 다른 판매·운영 경험이 있으면 근거입니다.
**다만 없는 것과 있는 것을 섞지 마십시오.** 경계를 흐리면 과장이 되고,
하나가 걸리면 나머지도 의심받습니다.

### 첫 고객은 레퍼런스 자산입니다

- 낮은 가격에 **이유를 붙여** 제공합니다
- 완료 후 **무엇이 부족했는지** 물어봅니다
- 리뷰를 요청하되 **내용을 지정하지 않습니다**
- **사례 사용 동의를 텍스트로 받습니다**

매출 규모로 자동 산정되므로 별도 신청이 필요 없습니다.

## 14. 납품과 전달

**결제와 전달은 별개 문제입니다.**

| 경로 | 전달 방식 | 직접 구현할 것 |
|---|---|---|
| 래피드 · 리틀리 | 결제 완료 시 자동 발송 | 없음 |
| 크몽 | 플랫폼이 처리 | 없음 |
| 스마트스토어 | **기본 기능 없음** | 외부 도구 또는 수작업 |
| PG 직결 | 결제 성공 신호만 수신 | 웹훅 서버 + 발송 로직 |

스마트스토어는 **센드맨 같은 외부 도구를 연동하면** 주문 즉시 발송할 수 있습니다.
질문을 "자동 발송이 되는가"가 아니라 **"무엇을 붙이면 자동이 되는가"**로 바꿔야 합니다.

### 채널 선택 전 확인 세 가지

1. **결제 완료 시 자동 발송이 되는가**
2. **파일 교체 시 기존 구매자도 최신본을 받는가** — 아니면 개정 때마다 전체 재발송
3. **다운로드 제한이 있는가** — 있으면 "평생 소장"으로 표기할 수 없습니다

### 자동 발송이라면

- 파일이 실제로 첨부됐는지 확인합니다
- **본인이 직접 1건 결제해 봅니다.** 5분이면 되고 사고를 막습니다

## 15. 법무와 세무

> 실무 정리이며 법률 자문이 아닙니다. 규모가 커지면 전문가 확인이 필요합니다.

### ① 사업자등록과 통신판매업

**사업자등록**은 계속·반복 판매하면 필요합니다. 홈택스에서 온라인 처리됩니다.

**통신판매업 신고**는 별개 절차이고, **면제 기준이 있습니다.**

> **직전 연도 통신판매 거래 50회 미만**
> **또는**
> **부가가치세법상 간이과세자**

"또는"입니다. 간이과세자 기준은 **연 매출 1억 400만원 미만**입니다.
시작 단계라면 대부분 면제입니다. 다만 **면제라도 판매 페이지에 사업자 정보는
표시해야 합니다.**

신고번호를 조회하면 "번호: 1" 같은 값이 보이는데 **그건 검색 결과 순번이지
신고번호가 아닙니다.** 실제 번호는 제0000-지역명-0000호 형식입니다.

### ② 판매 페이지 필수 표기

상호 · 대표자명 · 사업장 주소 · 전화번호 · 이메일 · 사업자등록번호 ·
통신판매업 신고번호.

**전화번호가 의무입니다.** 개인 휴대폰을 공개하면 스팸이 유입되므로
**통신사 투넘버 부가서비스**를 쓰십시오. 앱에서 즉시 개통되고 월 3천원대입니다.

### ③ 환불 규정

"환불은 결제하신 채널의 정책을 따릅니다"로 끝내면 안 됩니다.
**분쟁 시 규정을 고지하지 않은 쪽이 불리합니다.**

디지털 상품은 조건을 갖추면 청약철회를 제한할 수 있습니다.
근거는 전자상거래법 제17조 제2항 제5호이고 **핵심 조건이 사전 고지**입니다.

```
[전달 전]
파일이나 다운로드 링크를 보내드리기 전이면 전액 환불됩니다.

[전달 후]
파일을 받으신 뒤에는 청약철회가 제한됩니다. 디지털 파일은 전달 즉시
복제가 가능하기 때문이며, 이 안내가 전자상거래법 제17조 제2항 제5호가
요구하는 사전 고지입니다.

[하자]
파일이 열리지 않거나 상세페이지 설명과 다른 경우는 하자이므로
환불 대상입니다.

[미리보기]
구매 전에 앞부분을 확인하실 수 있습니다.
```

**용역(②③)은 구조가 다릅니다.** 착수 후에는 기 진행분 대가가 발생하므로
견적서에 **중도 해지 시 정산 기준**을 미리 적어둡니다.

### ④ 표시광고법

**수익 금액을 약속하지 않습니다.** "월 300 가능", "따라만 하면 수익화" 같은
표현은 거짓·과장 광고가 될 수 있고, 분쟁 시 전액 환불에 행정 처분까지 갑니다.
실무적으로도 **이런 문구를 쓴 상품이 환불 요구가 가장 많습니다.**

### ⑤ 부가세와 세금계산서

- 판매가에 **부가세 포함 여부를 사전에 정합니다**
- **법인 대상이면 세금계산서 발행 여부가 결정적입니다.** 발행이 안 되면
  상대는 구매 품의를 올릴 수 없습니다. ②③번 모델에서 특히 차이가 큽니다

금지
