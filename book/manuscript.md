# AI 활용할 줄은 아는데 어떻게 수익화 할까

네 가지 수익화 모델과 첫 입금까지의 거리

---

## 이 책이 하는 일

AI를 쓸 줄은 압니다. 프롬프트도 짜고, 자동화도 돌려보고, 뭔가 만들어도 봤습니다.

그런데 **통장에는 아무 일도 안 일어났습니다.**

이 책은 그 사이를 다룹니다. 활용과 수익 사이에는 정해진 단계가 있고,
대부분은 **첫 단계에서 멈춥니다 — 뭘 팔지를 안 정했기 때문입니다.**

무엇을 다루는지 먼저 밝히겠습니다.

| 다루는 것 | 다루지 않는 것 |
|---|---|
| 수익화 경로 네 가지와 **실제 시장 단가** | AI 도구 사용법 (쓸 줄 안다는 전제) |
| 내 상황에 맞는 경로 고르는 기준 | 코딩 강의 |
| 첫 고객을 만드는 순서 | 광고 집행·퍼포먼스 마케팅 |
| 가격을 정하는 법 | 법률·세무 자문 (실무 정리까지만) |
| 결제·전달·법 — 실제로 돈이 들어오게 하는 부분 | |

**숫자는 전부 확인해서 넣었습니다.** 크몽 카테고리의 실제 등록 단가, 플랫폼별
수수료, 통신판매업 면제 기준 조항까지. 제 머릿속에서 나온 추정치는 이 책에
없고, 확인 시점과 확인 방법을 부록 C에 따로 정리해 뒀습니다.

그리고 **틀렸던 것도 적었습니다.** 저는 스마트스토어에 파일 자동발송이 되는 줄
알고 이틀을 날렸습니다. 그런 걸 미리 알려주는 게 이 책의 일입니다.

목차를 보시고 이미 다 아는 내용이면 덮으십시오. 그게 서로한테 낫습니다.

---

## 1. 활용은 하는데 왜 돈이 안 되나

솔직하게 세어봅시다. AI로 만들어본 것들이 있으실 겁니다.
그중에 **돈을 받아본 게 몇 개입니까.**

이유는 실력이 아닙니다. 대부분 여기서 멈춥니다.

> **도구는 배웠는데, 무엇을 팔 것인지를 안 정했다.**

"AI로 뭘 할 수 있는가"와 "누가 나에게 돈을 낼 것인가"는 다른 질문입니다.
전자는 기술 문제고 후자는 상품 문제인데, 대부분 전자만 계속 파고듭니다.
도구가 늘어도 통장이 그대로인 게 그 때문입니다.

### 순서가 이렇습니다

```
①어떤 모델로 벌 것인가  →  ②구체적으로 뭘 팔 것인가  →  ③첫 고객
      →  ④가격  →  ⑤신뢰  →  ⑥결제·전달·법  →  입금
```

**대부분 ①을 건너뛰고 ⑥부터 걱정합니다.** 결제를 어떻게 붙이지, 사업자등록을
해야 하나. 그런데 팔 게 안 정해졌으면 그건 전부 이릅니다.

이 책은 ①부터 갑니다.

## 2. AI로 돈 버는 방법은 네 가지뿐입니다

다양해 보이지만 구조는 넷입니다. 그리고 **넷은 서로 완전히 다른 사업입니다.**
단가도, 첫 입금까지 걸리는 시간도, 늘어나는 방식도 다릅니다.

### ① 만들어서 판다 — 제품

전자책, 템플릿, 프롬프트 팩, 노션 서식, GPTs, 자동화 스크립트.
**한 번 만들어 여러 번 팝니다.**

- **단가** — 크몽 기준 최저 5,000원부터 등록됩니다. 전자책·템플릿류는
  1만~5만원대가 흔하고, 그 이상은 잘 안 팔립니다
- **첫 입금까지** — 며칠. 만들고 등록하면 그날 팔릴 수도 있습니다
- **늘어나는 방식** — 수량. 내가 자는 동안에도 팔립니다
- **한계** — **단가가 낮아 수량이 필요합니다.** 3만원짜리로 300만원을 만들려면
  100개를 팔아야 하는데, 그러려면 사람이 있어야 합니다

### ② 만들어준다 — 제작 대행

남의 업무를 자동화해 주거나, 챗봇·도구를 만들어 줍니다.

- **단가** — 업무 자동화·매크로 제작이 **평균 20만원 수준**입니다.
  간단한 엑셀 자동화는 15만원부터, 파이썬 스크립트로 데이터 수집이나
  API 연동이 들어가면 **30만~100만원대**, 복잡한 프로세스 자동화는
  **200만원대**까지 갑니다
- **챗봇은 자릿수가 다릅니다.** 룰 기반이 300만~1,000만원 구간입니다
- **첫 입금까지** — 1~3주. 문의받고 견적 내고 만들고 납품하는 시간
- **늘어나는 방식** — 단가와 시간. 내 시간을 파는 구조입니다
- **한계** — **내가 멈추면 매출도 멈춥니다.** 그리고 시간이 상한입니다

### ③ 대신 돌려준다 — 운영 대행·구독

만들어주고 끝이 아니라 매달 돌려줍니다. 콘텐츠 발행, 데이터 수집,
리포트 자동 생성 같은 것들.

- **단가** — 월 단위. LLM API를 태우는 서비스의 운영비만 **월 30만~200만원**
  규모가 잡힙니다. 여기에 내 마진이 붙습니다
- **첫 입금까지** — 1개월 이상. 신뢰가 먼저 필요합니다
- **늘어나는 방식** — **누적됩니다.** 이번 달 계약이 다음 달에도 들어옵니다
- **한계** — 팔기 가장 어렵습니다. 매달 돈이 나가는 결정이라 문턱이 높습니다

### ④ 가르친다 — 강의·컨설팅

- **단가** — 시간당 또는 회차당. 폭이 매우 넓습니다
- **첫 입금까지** — 신뢰가 쌓인 뒤. 가장 오래 걸립니다
- **늘어나는 방식** — 시간, 또는 녹화해서 제품(①)으로 전환
- **한계** — **실적이 없으면 시작 자체가 안 됩니다.** 가르치려면 먼저
  해낸 게 있어야 합니다

### 한 장으로

| | 단가 | 첫 입금 | 늘어나는 방식 | 막히는 지점 |
|---|---|---|---|---|
| ① 제품 | 5천~5만원 | **며칠** | 수량 | 사람이 없다 |
| ② 제작 대행 | 15만~200만원 | 1~3주 | 시간 | 내가 멈추면 끝 |
| ③ 운영 대행 | 월 단위 | 1개월+ | **누적** | 팔기 어렵다 |
| ④ 교육 | 넓음 | 오래 | 시간 | 실적이 필요 |

> 단가는 2026년 7월 확인 기준이고 바뀝니다. 확인 방법은 부록 C에 있습니다.

## 3. 넷 중 무엇을 고를 것인가

여기서 대부분 틀립니다. **제일 좋아 보이는 걸 고르기 때문입니다.**

①번이 제일 매력적으로 보입니다. 자는 동안 돈이 들어온다니까요.
그런데 ①번은 **사람이 없으면 0원입니다.** 팔로워도 없고 검색 유입도 없는
상태에서 전자책을 올리면 아무 일도 안 일어납니다.

### 두 가지만 보면 됩니다

**하나. 지금 돈이 얼마나 급한가.**

**둘. 나에게 사람이 있나** — 팔로워, 기존 고객, 업계 인맥 중 아무거나.

이 두 개로 갈립니다.

| | 사람이 있다 | 사람이 없다 |
|---|---|---|
| **급하다** | ① 제품 — 바로 팔린다 | **② 제작 대행** — 한 건이 크다 |
| **안 급하다** | ③ 운영 대행 — 누적을 쌓는다 | ② 로 시작해 ①③ 으로 옮긴다 |

**사람이 없고 돈이 급하면 ②번입니다.** 한 건에 30만~100만원이라
몇 건이면 됩니다. 반대로 ①번은 30만원을 만들려면 3만원짜리를 열 개
팔아야 하고, 사람이 없으면 열 명이 안 모입니다.

**이게 이 장에서 제일 중요한 문장입니다.**
사람이 없을 때는 **적은 사람에게 비싸게 파는 쪽**이 맞습니다.

### 그런데 대부분 반대로 합니다

전자책이 만들기 쉬워 보이니까 그것부터 만듭니다. 만들고 나서
"사람이 없네"를 깨닫습니다. 순서가 뒤집힌 겁니다.

**②번으로 첫 수익을 만들고, 그 과정에서 생긴 사례와 고객으로 ①③번을
여는 게 실제 순서입니다.**

그리고 ②번을 하면 부수적으로 얻는 게 큽니다.
- **후기가 생깁니다.** 이게 나중에 ①③번의 자산이 됩니다
- **실제 고객이 뭘 아파하는지 알게 됩니다.** ①번에서 뭘 팔지가 여기서 나옵니다
- **가격 감각이 생깁니다**

### 다만 ②번의 한계는 분명합니다

내 시간이 상한입니다. 그래서 **②번에 영원히 머물면 안 됩니다.**
같은 의뢰가 세 번 들어오면 그건 제품(①)이나 구독(③)으로 바꿀 신호입니다.

## 4. 그래서 구체적으로 뭘 팔 것인가

모델을 골랐으면 이제 품목입니다.

### 내가 가진 것에서 출발하지 마십시오

가장 흔한 실수입니다. 만든 게 있으면 그걸 팔고 싶어집니다.
그런데 시장은 **내가 뭘 갖고 있는지에 관심이 없습니다.** 자기가 뭘 아픈지에만
관심이 있습니다.

제가 본 사례가 이걸 정확히 보여줍니다. 어떤 사람이 AI에게 돈을 벌어오라고
시켰더니, AI가 컴퓨터를 뒤져서 이미 있던 자료로 8만 9천원짜리 키트를
만들었습니다. **안 팔렸습니다.** 누구의 어떤 아픔을 건드리는지가 없었기
때문입니다.

두 번째로 만든 게 팔렸습니다. 주제가 **"만들 줄은 아는데 왜 돈은 못 벌까"**
였습니다. 상대가 아픈 곳에서 출발한 겁니다.

### 후보를 뽑는 질문 하나

여러 개 물어봐야 소용없습니다. 이거 하나면 됩니다.

> **최근에 뭔가 해결하려고 검색했는데 답이 안 나왔던 게 있나.**

답이 안 나왔다는 건 시장에 자료가 없다는 뜻이고, 그게 빈칸입니다.
그리고 내가 직접 검색했다는 건 **최소한 한 명에게는 수요가 있었다**는
증거입니다.

이 책이 그렇게 나왔습니다. 스마트스토어에 파일 자동발송이 되는지 검색했는데
명확한 답이 없었습니다. 통신판매업 면제 기준도 마찬가지였습니다.
**답이 없어서 직접 확인해야 했던 것들의 목록이 곧 목차가 됐습니다.**

### 모델별 품목 후보

**② 제작 대행으로 간다면** — 남이 반복하는 일을 찾습니다.
엑셀 정리, 자료 수집, 보고서 작성, 재고·주문 대조, 고객 응대 초안.
**화려한 기술이 필요 없습니다.** 15만원짜리 엑셀 자동화가 시장에서
꾸준히 팔리는 건 그 일이 지겨운 사람이 많기 때문입니다.

**① 제품으로 간다면** — 내가 반복해서 설명한 것을 찾습니다.
같은 걸 세 번 설명했으면 그건 상품입니다.

**③ 운영 대행으로 간다면** — ②번 고객에게 "이거 매달 돌려드릴까요"를
물어보는 게 가장 빠릅니다. 새 고객을 찾는 것보다 쉽습니다.

### 후보 검증 — 지어낸 시장 조사에 속지 마십시오

AI에게 "이 시장 규모가 얼마야"라고 물으면 **그럴듯한 숫자를 만들어냅니다.**
검색을 못 하는데 물으니까 지어내는 겁니다. 저도 이 책 부록의 프롬프트를
처음 쓸 때 이걸로 당했습니다.

대신 이렇게 하십시오.

1. 후보 품목을 크몽·숨고 같은 곳에서 **그대로 검색**합니다
2. 등록된 서비스가 **몇 개인지, 얼마인지, 후기가 몇 개인지** 봅니다
3. 후기가 달린 서비스가 있으면 **그 시장은 실재합니다**
4. 하나도 없으면 둘 중 하나입니다 — 아무도 안 하는 빈칸이거나, 수요가 없거나

**후기 수가 가장 정직한 지표입니다.** 등록만 되고 후기 0개인 카테고리는
위험합니다.

## 5. 첫 고객은 어디서 오나

### 아는 사람부터입니다

낯선 사람 1,000명보다 아는 사람 20명이 낫습니다.

특히 ②번(제작 대행)은 **콜드로 시작하기가 오히려 쉽습니다.**
단가가 높아서 받는 쪽이 읽을 이유가 있기 때문입니다.
"엑셀 작업 자동화해 드립니다"는 상대에게 실제 이득이 보입니다.

반대로 **3만원짜리 전자책을 콜드 DM으로 파는 건 안 됩니다.**
받는 쪽 입장에서 성가심 대비 얻는 게 없습니다. 그리고 계산이 안 맞습니다 —
전환 1%로 30권을 팔려면 3,000통을 보내야 하는데, 그건 스팸이고
계정이 죽습니다.

**단가가 접근 방식을 결정합니다.**

| 단가 | 접근 |
|---|---|
| 30만원 이상 | 1:1 제안이 통한다. 상대에게 이득이 계산된다 |
| 3만원 안팎 | 1:1 제안이 안 통한다. 답변으로 존재해서 오게 만든다 |

### 낮은 단가일 때 — 답해서 오게 만듭니다

팔려고 쓴 글은 안 퍼지고, **도와주려고 쓴 글은 퍼집니다.**

제가 추적한 사례에서 이게 결정적이었습니다. 판매 글만 올릴 때는 아무것도
안 팔렸습니다. 그러다 **판매와 무관한 질문까지 받는 상담 창구를 열었더니**
질문이 몰렸고, 그때부터 알고리즘을 탔고, 그 뒤에 팔리기 시작했습니다.

실행은 단순합니다.

- 사람들이 이미 **공개적으로 질문한 곳**을 찾습니다
- **링크 없이 답만 합니다.** 대부분의 커뮤니티가 홍보를 금지하고,
  링크가 붙는 순간 답변이 광고가 됩니다
- 링크는 프로필에 둡니다. 답이 좋으면 프로필을 눌러봅니다
- **답변 글이 판매 글보다 최소 세 배 많아야 합니다**

### 판매 과정 자체를 콘텐츠로 쓰십시오

상품 소개는 한 번 하면 더 할 말이 없습니다. 그런데 **판매 진행을 중계하면
쓸 거리가 계속 생깁니다.**

올렸습니다 → 아직 하나도 안 팔렸습니다 → 방금 첫 판매가 났습니다 →
세 건째입니다 → 절반 왔습니다 → 마감했습니다.

**안 팔리는 것조차 콘텐츠가 됩니다.** "아직 0건입니다"는 실패 보고가 아니라
다음 편 예고입니다. 이걸 하는 사람이 거의 없어서 눈에 띕니다.

---

## 6. 가격을 어떻게 매기나

### 모델별로 다릅니다

**② 제작 대행** — 시간으로 계산하고 시장가와 맞춰봅니다.
평균 20만원, 30만~100만원이 주력 구간이라는 걸 알고 들어가야 합니다.
**첫 건은 낮게 잡되 왜 낮은지 밝히십시오.** "첫 사례라서"가 가장 정직하고
잘 먹힙니다. 그리고 후기를 받으십시오. 그게 다음 건의 단가입니다.

**① 제품** — 정찰제로 걸어두면 아무 일도 안 일어납니다.
오늘 사도 3만원, 내일 사도 3만원이면 내일 삽니다. 그리고 잊습니다.

### 제품이라면 — 한정 수량 + 건당 인상

제가 본 것 중 가장 잘 돌아간 구조입니다.

- 수량을 한정합니다
- **한 개 팔릴 때마다 가격을 조금씩 올립니다**
- 다 나가면 판매를 닫습니다

효과가 세 겹입니다.

**하나. 지금 살 이유가 생깁니다.** 내일은 더 비쌉니다.
**둘. 중계할 거리가 생깁니다.** "3권 나갔고 가격이 올랐습니다"가 그 자체로 글입니다.
**셋. 초기 구매자가 보상받습니다.** 먼저 산 사람이 제일 싸게 샀으니
후기 부탁하기가 편합니다.

### 지켜야 할 것

**규칙을 공표하고 지키십시오.** 30개 한정이라고 했으면 30개에서 닫습니다.
잘 팔린다고 슬쩍 늘리면 다음 판매 때 아무도 안 믿습니다.
**신뢰가 가격 정책보다 비쌉니다.**

**현재 가격을 계속 노출하십시오.** 올라가는 게 안 보이면 그냥 정찰제입니다.

**너무 싸게 걸지 마십시오.** 싸면 오히려 안 팔립니다. 시간을 쓸 가치가
없다고 판단됩니다.

## 7. 후기가 0개일 때

처음 파는 사람은 전부 여기서 걸립니다. 후기가 0개인데 누가 사느냐.
그리고 안 팔리니까 후기가 안 쌓입니다. 닫힌 고리입니다.

거짓 후기는 논외입니다. **불법이고, 들키고, 들키면 끝입니다.**

푸는 법은 하나입니다. **후기를 만들지 말고 대체하십시오.**
후기가 하는 일은 "이 사람 말이 사실인가"를 대신 확인해주는 것입니다.
그 일을 하는 다른 물건이 있으면 됩니다.

### 대체재 다섯 개

**하나. 미리보기.** 앞부분을 공개합니다. 읽어보고 판단하게 하는 게 남의
후기보다 셉니다. 그리고 이게 환불 분쟁도 같이 막습니다.

**둘. 그 자리에서 하는 시연.** 상대가 준 재료로 즉석에서 돌려 보여줍니다.
**위조가 불가능합니다.** 후기는 조작할 수 있지만 눈앞에서 도는 건 못 꾸며냅니다.
②번(제작 대행)에서는 이게 후기보다 결정적입니다.

**셋. 만든 과정의 기록.** 실패한 시도, 고친 흔적. **완벽한 결과물보다
틀렸다가 고친 기록이 더 신뢰를 줍니다.** 실패의 구체성은 겪은 사람만 씁니다.

**넷. 검증 가능한 사실.** 독자가 직접 확인할 수 있는 걸 넣으십시오.
하나가 맞으면 나머지도 믿어집니다.

**다섯. 관련된 다른 경력.** AI로 판 실적이 없어도 뭔가 팔아본 적이 있다면
그건 근거입니다. 사업자등록, 운영 중인 스토어처럼 **열어보면 확인되는 것**이
가장 강합니다. 다만 **없는 것과 있는 것을 섞지 마십시오.** 흐리는 순간
과장이 되고, 하나 걸리면 나머지도 의심받습니다.

### 첫 고객은 후기 공장입니다

매출로 보지 마십시오.

- 값을 낮게 걸고 **왜 낮은지 밝히십시오**
- 산 사람에게 어디가 부족했는지 물으십시오. 그 답이 다음 버전입니다
- 후기를 요청하되 **내용을 지정하지 마십시오.** 지정하는 순간 광고입니다

## 8. 어디서 결제받나 — 실제 수수료

여기부터는 실행입니다. 팔 게 정해졌다는 전제입니다.

한국에서 디지털 상품·서비스를 파는 경로는 넷인데, **성격이 완전히 다른데도
다들 뭉뚱그려 이야기합니다.**

**① PG (토스페이먼츠 등)** — 결제만 처리합니다. 상품 페이지도 파일 전달도
안 해줍니다. **PG를 붙였다고 자동발송이 되는 게 아닙니다.**

**② 마켓플레이스 (크몽 등)** — 손님이 이미 있습니다. 대신 심사가 있고
수수료가 높고, 손님이 내 손님이 아닙니다.

**③ 오픈마켓 스토어 (스마트스토어 등)** — 검색 유입이 강합니다.
그런데 **파일 자동발송 기능이 없습니다.**

**④ 디지털 상품 전용 스토어프론트** — 상품 페이지·결제·자동발송이 한 덩어리입니다.

### 실제 수수료 — 2026년 7월 확인 기준

| 플랫폼 | 수수료 | 정산 | 자동 발송 | 사업자등록 |
|---|---|---|---|---|
| 래피드 | **1.6%** | — | 결제 즉시 | 불필요 |
| 리틀리 | **1~5%** (판매량 늘면 하락) | 주 1회 자동 | 결제 즉시 | 연 20건까지 불필요 |
| 크몽 | **4.4~16.4%** (금액 구간별) | 월 말 영업일 | 있음 | 필요 (심사) |
| 스마트스토어 | 결제 **1.98~3.63%** (VAT 포함)<br>+ 판매 **2.73%** (VAT 별도) | 구매확정 후 D+3~D+7 | **없음** | 필요 |
| 탈잉 | **20%** | 월 2회 (15일·말일) | — | — |
| 클래스101 | **20% 이상** | — | — | 필요 (내부 승인) |
| 토스페이먼츠 (PG) | 일반 **3.4%**<br>영세 0.63% · 중소1 1.15%<br>중소2 1.40% · 중소3 1.74% | D+6 | 직접 구현 | 필요 (심사) |

> **이 수치는 확인 시점 기준이고 바뀝니다.** 스마트스토어만 해도 2025년에
> 두 차례 조정됐습니다. 본인 등급별 실제 요율은 각 플랫폼 정산 관리 화면에서
> 직접 확인하십시오.

### 읽어야 할 것 네 가지

**하나. 마켓플레이스와 스토어프론트가 열 배 넘게 차이 납니다.**
탈잉 20% 대 래피드 1.6%. 29,000원짜리를 팔면 전자는 5,800원, 후자는 464원을
뗍니다. **그 차이가 손님 유입의 값입니다.** 공짜는 없습니다.

**둘. 크몽은 금액 구간별이라 소액일수록 불리합니다.**
낮은 요율은 고액 거래에 붙습니다. **다만 ②번(제작 대행)처럼 단가가 높으면
얘기가 달라집니다** — 유입이 있는 곳에서 30만원짜리를 파는 게,
유입이 없는 곳에서 싸게 파는 것보다 낫습니다.

**셋. 스마트스토어는 수수료보다 정산이 문제입니다.**
합쳐도 6% 안팎이라 나쁘지 않은데, **정산이 구매확정 이후**라 주문부터
입금까지 실질 2~3주 걸립니다. 급하면 이 경로가 아닙니다.

**넷. PG 수수료는 등급에 따라 다섯 배 차이 납니다.**
일반 3.4%인데 영세는 0.63%입니다. 매출 규모로 자동 산정되므로
별도 신청이 필요 없습니다.

### 순서

| 단계 | 어디서 |
|---|---|
| 첫 판매 | 마켓플레이스(②번 모델) 또는 스토어프론트(①번 모델) |
| 자리 잡은 뒤 | 자체 채널로 옮겨 수수료를 줄인다 |
| 규모가 커지면 | PG 직결 |

거꾸로 가지 마십시오. PG부터 붙이면 심사 기다리고 전달 코드 짜다가
파는 걸 잊습니다. **파는 게 먼저입니다.**

## 9. 결제와 전달은 다른 문제입니다

이 문장 하나만 가져가셔도 됩니다. 저는 이걸 헷갈려서 이틀을 버렸습니다.

"결제 링크 만들었으니 팔 수 있겠네" — 아닙니다. 돈이 들어온 다음에
**물건이 상대 손에 들어가는 경로**가 따로 있어야 합니다.

### 경로별로 실제로 어떻게 되나 — 2026년 7월 확인 기준

| 경로 | 전달 방식 | 내가 만들 것 |
|---|---|---|
| 래피드 | 결제 완료 시 자동 발송 | 없음 |
| 리틀리 | 결제 완료 시 메일·카카오톡 자동 발송 | 없음 |
| 크몽 | 플랫폼이 처리 | 없음 |
| 스마트스토어 | **기본 기능 없음.** 발주/발송관리에서 사람이 처리 | 외부 도구 또는 수작업 |
| PG 직결 | 없음. 결제 성공 신호만 온다 | 웹훅 서버 + 발송 로직 |

**스마트스토어 항목을 다시 보십시오.** 저는 당연히 되는 줄 알고 이틀 동안
그쪽으로 계획을 짰습니다.

다만 **완전히 막힌 건 아닙니다.** 센드맨 같은 외부 도구를 붙이면 주문 즉시
파일이나 1회용 다운로드 코드를 보낼 수 있습니다. 그러니 질문을 바꿔야 합니다 —
**"자동발송이 되나"가 아니라 "무엇을 붙여야 자동이 되나"입니다.**

### 고르기 전에 물어볼 세 가지

**하나. 결제가 끝나면 자동으로 갑니까, 제가 보내야 합니까.**

**둘. 파일을 교체하면 이미 산 사람도 새 파일을 받습니까.**
링크가 고정되는 방식이면 파일만 갈아 끼우면 됩니다. 아니면 개정할 때마다
구매자 전원에게 다시 뿌려야 합니다. 스무 명은 되지만 이백 명은 못 합니다.

**셋. 다운로드에 제한이 있습니까.**
횟수 제한이나 기간 만료가 있으면 "평생 소장"이라고 쓰면 안 됩니다.
그건 허위 표시입니다.

### 수동 발송이라면

- **몇 시간 안에 보낼지 페이지에 적으십시오.** 안 적으면 "언제 오냐"는 문의가
  판매량만큼 옵니다. 12시간 정도가 무난합니다
- 파일은 클라우드에 두되 **업데이트할 때 링크를 바꾸지 마십시오.**
  새로 올리지 말고 같은 파일의 새 버전으로 덮어씁니다
- **링크가 퍼지는 건 못 막습니다.** 이 규모에서 DRM은 배보다 배꼽입니다.
  퍼지는 걸 전제로 가격을 정하고, 계속 업데이트해서 최신본은 나한테서만
  나오게 만드는 쪽이 현실적입니다

### 자동 발송이라면

할 일이 거의 없습니다. 두 개만 확인하십시오.

- 파일이 실제로 첨부됐는지 (등록만 하고 안 올린 채 판매를 여는 사고가 흔합니다)
- **본인이 직접 한 건 사보십시오.** 다른 결제수단으로 최저가 상품을 걸어놓고
  사서, 메일이 오는지 파일이 열리는지 확인합니다. 5분 걸리고 사고를 막습니다

## 10. 법 — 실제로 걸리는 것 다섯

여기가 가장 안 다뤄지는 부분이고, 사고가 나면 제일 아픈 부분입니다.

> 아래는 실무에서 통용되는 정리이고 법률 자문이 아닙니다.
> 규모가 커지거나 분쟁이 생기면 세무사·변호사에게 확인하십시오.

### ① 사업자등록과 통신판매업 신고

**사업자등록**은 계속·반복해서 판매하면 필요합니다. 홈택스에서 온라인으로
됩니다.

**통신판매업 신고**는 별도 절차입니다. 관할 구청·시청에 합니다.
**그런데 면제 기준이 있습니다. 이걸 모르고 며칠 쓰는 사람이 많습니다.**

공정거래위원회 고시상 다음 **둘 중 하나**면 신고 의무가 면제됩니다.

> **직전 연도 통신판매 거래 횟수가 50회 미만**인 경우
> **또는**
> **부가가치세법상 간이과세자**인 경우

"또는"입니다. 둘 다일 필요가 없습니다.
간이과세자 기준은 **연 매출 1억 400만원 미만**입니다.

| 상황 | 신고 |
|---|---|
| 이제 시작, 작년 판매 0건 | 면제 (50회 미만) |
| 간이과세자 | 면제 (매출 기준 유지되는 동안) |
| 작년 50회 이상 팔았고 일반과세자 | 필요 |

**시작 단계에서 신고부터 하겠다고 며칠 쓰지 마십시오.** 대부분 면제입니다.
다만 면제라도 **판매 페이지에 사업자 정보는 표시해야 합니다.**

**한 가지 주의.** 신고번호를 조회하면 "번호: 1" 같은 게 뜨는데
**그건 검색 결과 순번이지 신고번호가 아닙니다.** 실제 번호는
제0000-지역명-0000호 형태입니다.

### ② 판매 페이지에 반드시 들어가야 하는 것

전자상거래법상 판매자 정보를 표시해야 합니다.

상호 · 대표자명 · 사업장 주소 · 전화번호 · 이메일 · 사업자등록번호 ·
통신판매업 신고번호.

**전화번호가 의무라는 게 걸립니다.** 개인 휴대폰을 공개 페이지에 올리면
스팸과 영업 전화가 옵니다. **통신사 투넘버 부가서비스가 가장 빠릅니다** —
앱에서 몇 분이고 월 3천원대입니다. 한번 퍼진 번호는 못 주워담습니다.

### ③ 환불 규정 — 여기가 제일 위험합니다

가장 흔한 실수가 이겁니다.

> 환불은 결제하신 채널의 정책을 따릅니다.

이렇게 쓰면 안 됩니다. **분쟁이 나면 규정을 안 밝힌 쪽이 불리합니다.**

디지털 상품은 조건을 갖추면 청약철회를 제한할 수 있습니다.
근거는 전자상거래법 제17조 제2항 제5호이고, **핵심 조건이 사전 고지**입니다.
살 때 몰랐다고 하면 제한이 안 먹힙니다.

그래서 이렇게 씁니다. 그대로 쓰셔도 됩니다.

```
[전달 전]
파일이나 다운로드 링크를 보내드리기 전이면 전액 환불됩니다.

[전달 후]
파일을 받으신 뒤에는 청약철회가 제한됩니다. 디지털 파일은 전달 즉시
복제가 가능하기 때문이며, 이 안내가 전자상거래법 제17조 제2항 제5호가
요구하는 사전 고지입니다.

[하자]
파일이 열리지 않거나 상세페이지 설명과 다른 경우는 하자이므로
환불 대상입니다.

[미리보기]
구매 전에 앞부분을 확인하실 수 있습니다.
```

**마지막 항목이 중요합니다.** 미리 볼 수 있게 해두면 "속았다"는 분쟁이
거의 안 생깁니다. **환불 규정보다 미리보기가 더 강한 방어입니다.**

그리고 **플랫폼 약관을 그대로 베끼지 마십시오.** 제가 본 사례 중에
플랫폼의 "판매자는 3일 이내 취소 가능" 조항을 구매자 환불 조건으로 잘못 읽고
상세페이지에 옮겨 적은 일이 있었습니다. 판매자 쪽 규정을 구매자 쪽에 붙인
겁니다.

### ④ 표시광고법

짧게 끝냅니다. **얼마를 벌 수 있다고 쓰지 마십시오.**

"월 300 가능", "3일이면 본전", "따라만 하면 수익화" — 전부 위험합니다.
거짓·과장 광고가 될 수 있고, 분쟁이 나면 전액 환불에 행정 처분까지 갑니다.

그리고 실무적으로도 **이런 문구를 쓴 상품은 환불 요구가 훨씬 많이 들어옵니다.**
기대치를 내가 올려놨기 때문입니다.

대신 팔 수 있는 건 **시간과 과정**입니다. "두 시간 걸리던 걸 몇 분에",
"제가 확인한 것들의 목록". 이건 검증 가능하고 약속을 어길 일이 없습니다.

### ⑤ 부가세와 세금계산서

- **판매가에 부가세를 포함할지 별도로 받을지** 미리 정하십시오.
  나중에 바꾸면 이미 산 사람과 형평이 안 맞습니다
- **법인·대행사에 팔 거라면 세금계산서 발행 여부가 결정적입니다.**
  안 되면 그쪽은 구매 결재를 못 올립니다. 여기가 열려 있으면
  개인 대상보다 단가를 훨씬 높게 갈 수 있습니다 — ②③번 모델에서 특히 큽니다

## 11. 계속 굴리기

첫 수익이 나면 그다음이 진짜입니다.

**같은 의뢰가 세 번 들어오면 제품으로 바꾸십시오.** ②번에서 반복되는 일은
①번이나 ③번의 씨앗입니다. 매번 새로 만들지 마십시오.

**②번 고객에게 ③번을 제안하십시오.** "이거 매달 돌려드릴까요"가
새 고객 찾기보다 훨씬 쉽습니다.

**모든 건에서 후기와 사례를 남기십시오.** 이게 다음 단가입니다.
7장에서 말한 대체재가 여기서 진짜 후기로 바뀝니다.

그리고 **안 팔린다고 사흘 만에 접지 마십시오.** 사례를 추적해보면
대부분 초반에는 아무 반응이 없습니다. 방향을 한 번 틀고 나서 터집니다.
접기 전에 한 번은 틀어보십시오.

## 부록 A. 복붙 프롬프트 {: .page-break }

그대로 복사해서 쓰시면 되고, 대괄호 안만 본인 것으로 바꾸시면 됩니다.

> **여덟 개 다 돌려보고 고친 것들입니다.** 처음 쓴 버전에서 세 군데가
> 깨졌습니다. 어디가 왜 깨졌는지도 같이 적었습니다.
>
> 공통으로 걸린 함정이 하나 있습니다. **모델은 모른다고 말하는 대신
> 그럴듯하게 지어냅니다.** 시장 규모, 경쟁 자료 목록, 법 조항 번호처럼
> 검증이 필요한 걸 요구하면 확신에 찬 거짓말이 돌아옵니다.
> 그래서 아래 프롬프트들은 **모델이 만들어낼 수 없는 건 애초에 안 시킵니다.**

### A-1. 수익화 모델 고르기

```
내 상황이다.
- AI로 할 수 있는 것: [구체적으로]
- 쓸 수 있는 시간: [주당 몇 시간]
- 지금 나에게 있는 사람: [팔로워/기존 고객/업계 인맥, 없으면 없다고]
- 돈이 급한 정도: [당장 필요 / 3개월 여유 / 길게 봐도 됨]

아래 네 가지 중 나에게 맞는 순서를 매기고, 왜 그 순서인지 적어라.
① 제품을 만들어 판다 (단가 낮음, 첫 입금 며칠, 사람이 없으면 0)
② 제작 대행 (단가 15만~200만원, 첫 입금 1~3주, 내 시간이 상한)
③ 운영 대행·구독 (월 단위, 첫 입금 1개월+, 누적됨, 팔기 어려움)
④ 강의·컨설팅 (실적이 먼저 필요)

각 순위마다 이걸 적어라.
- 왜 이 순위인가 (내 상황의 어떤 조건 때문인가)
- 첫 수익까지 내가 해야 할 일 3가지
- 이 모델에서 내가 막힐 가능성이 가장 큰 지점

규칙
- 수익 금액을 예측하지 마라. 얼마를 벌 수 있다는 표현 금지
- 시장 규모나 성공률 같은 숫자를 지어내지 마라
- 내가 준 조건에 없는 사실을 가정하지 마라
```

### A-2. 팔 것 정하기

```
나는 [내가 만들 수 있는 것 / 겪은 문제]를 가지고 있고,
[①제품 / ②제작 대행 / ③운영 대행] 모델로 가려고 한다.

이걸로 팔 수 있는 후보를 5개 뽑아줘.

각 후보마다 다음을 적어라.
1. 누가 산다 (구체적인 상황으로. "직장인" 말고
   "AI 구독료는 내는데 아직 한 푼도 못 번 사람")
2. 그 사람이 지금 아픈 지점 한 문장
3. 이 후보를 내가 직접 검증할 수 있는 검색어 3개
   (크몽·숨고에 그대로 넣어볼 수 있는 형태로)
4. 그 사람이 지금 이 문제를 어떻게 때우고 있을 것 같은가

마지막에 5개를 폭 기준으로 줄 세우고 가장 좁은 것과 넓은 것을 표시해라.

규칙
- 내가 가진 것에서 출발하지 말고 상대가 아픈 곳에서 출발해라
- **숫자를 추정하지 마라.** 시장 규모, 검색량, 경쟁 서비스 수는
  네가 확인할 수 없다. 모르면 모른다고 해라
- **실재하는 서비스·책 제목을 예로 들지 마라.** 확인할 수 없으면 짓지 마라
- 수익 금액을 약속하는 표현 금지
```

> **고친 부분.** 처음엔 3번이 "대략적인 구매자 풀 크기와 그 근거"였습니다.
> 돌려보니 **없는 숫자와 없는 서비스 이름이 그럴듯하게 나왔습니다.**
> 검색을 못 하는데 물으니 지어낸 겁니다. 그래서 추정을 시키는 대신
> **내가 직접 확인할 검색어를 달라고** 바꿨습니다. 판단은 내가 합니다.

### A-3. 제안서 (②③번 모델용)

```
상대: [업종/규모/내가 파악한 상황]
내가 제안할 것: [무엇을 자동화·제작할 것인가]
내 단가 생각: [금액]

1:1 제안 메시지를 써라.

구조
1. 상대가 지금 반복하고 있을 일 한 문장 (추측이면 추측이라고 밝힌다)
2. 그게 얼마나 걸리는지, 자동화하면 어떻게 되는지
3. 내가 뭘 만들 것인지 구체적으로
4. 금액과 기간
5. 부담 없이 거절할 수 있게 하는 마무리

규칙
- 300자 이내. 길면 안 읽는다
- 성과나 절감액을 숫자로 약속하지 마라. 확인 안 된 건 추정이라고 밝혀라
- 상대 회사를 조사한 척하지 마라. 아는 것만 쓴다
- 첫 건이면 낮은 단가인 이유를 밝혀라 ("첫 사례라서")
```

### A-4. 상세페이지 / 서비스 소개

```
아래를 파는 페이지 문안을 써라.

[상품 또는 서비스 설명 붙여넣기]

구조는 이 순서로 간다.
1. 후킹 — 상대가 지금 겪고 있는 상태를 한 문장으로. 상품 얘기 금지
2. 문제 — 왜 그 상태가 계속되는지
3. 이것이 다루는 것
4. 이것이 다루지 않는 것 — 반드시 넣어라. 신뢰가 여기서 나온다
5. 미리보기 또는 시연 안내
6. 가격과 (제품이라면) 수량 정책
7. 환불 규정
8. 판매자 정보

규칙
- 수익 보장 표현 금지
- 없는 후기를 만들거나 암시하지 마라
- "지금 사야 하는 이유"는 가격 정책으로만 만들어라. 공포로 만들지 마라
```

### A-5. 환불 규정

```
디지털 상품 판매용 환불 규정을 써라.

근거 조항은 아래를 그대로 쓴다. 다른 조항 번호를 만들지 마라.
  전자상거래 등에서의 소비자보호에 관한 법률 제17조 제2항 제5호

포함할 것
- 전달 전: 전액 환불
- 전달 후: 청약철회 제한. 위 조항을 인용하고,
  이 안내 자체가 사전 고지임을 밝힌다
- 하자(열림 불가, 설명과 불일치): 환불
- 구매 전 미리보기 안내
- 외부 채널 결제 시 해당 채널 절차가 함께 적용된다는 안내

금지
- "채널 정책을 따릅니다"로 끝내는 것
- **위에 준 것 외의 조항 번호나 법령명을 쓰는 것**
- 플랫폼 약관을 그대로 옮기는 것.
  판매자에게 적용되는 조항과 구매자에게 적용되는 조항을 구분해라
```

> **고친 부분.** 처음엔 "근거 조항을 명시하라"고만 했습니다.
> 그랬더니 **조항 번호를 기억으로 써서 틀린 게 나왔습니다.**
> 법 조항은 모델이 가장 그럴듯하게 틀리는 영역입니다.
>
> 이건 법 조항만의 얘기가 아닙니다. **정확해야 하는 고유명사·번호·수치는
> 물어보지 말고 주십시오.** 물어보는 순간 검증 책임이 나한테 넘어옵니다.

### A-6. 판매 중계 글

```
지금 상황: [예: 방금 3건째 판매됨. 현재 가격 32,000원. 목표 30건]

이 상황을 SNS 글로 써라.

규칙
- 상품 소개가 아니라 진행 중계다. 지금 벌어진 일 하나만 다뤄라
- 500자 이내
- 판매 링크는 본문에 넣지 말고 "댓글에 두겠습니다"로 처리
- 수익 금액을 자랑하는 톤 금지. 사실만 담담하게
- 아직 안 팔렸으면 안 팔렸다고 그대로 써라. 그것도 중계다
- 마지막 줄은 다음이 궁금해지게 끝내라
```

### A-7. 상담 답변

```
너는 [주제] 관련 질문에 답하는 담당자다.

원칙
- 판매와 무관한 질문이어도 성실히 답한다
- 답변에 상품 얘기를 넣지 마라. 상대가 물어보면 그때만 안내한다
- 모르면 모른다고 하고, 확인해서 알려주겠다고 해라
- 다음은 절대 하지 마라
  · 수익이나 성과를 약속하는 표현
  · 우리 상품에 없는 기능을 말하는 것
  · 확실하지 않은 법·세무 사항을 단정하는 것
- 판단이 안 서면 답하지 말고 사람에게 넘긴다고 표시해라

길이: 3문장 이내. 길면 안 읽는다
```

### A-8. 출시 전 점검

```
아래 문안을 출시 전 점검해라.

[문안 붙여넣기]

체크할 것
1. 수익·성과를 약속하는 표현이 있는가 (있으면 전부 지적)
2. 없는 후기를 암시하는 표현이 있는가
3. 환불 규정에 전달 전/후/하자가 다 있는가
4. 판매자 정보 필수 항목이 다 있는가
   (상호, 대표자, 주소, 전화, 이메일, 사업자번호, 통신판매업 신고번호)
5. 전달 방식과 소요 시간이 명시돼 있는가
6. 채우지 않고 남은 자리표시자가 있는가
7. 확인되지 않은 사실을 단정한 문장이 있는가

각 항목을 통과/실패로 판정하고, 실패는 수정안을 함께 제시해라.
```

> **A-4 도 고쳤습니다.** 원고 작성 프롬프트에 "내가 직접 확인하지 않은
> 사실은 쓰지 마라"라고 썼었는데, **모델은 내가 뭘 확인했는지 모릅니다.**
> 지시가 작동하지 않았고 확인 안 된 수치가 그대로 들어갔습니다.
> "네가 쓰지 말고 자리만 비워둬라"로 바꾸니 그때부터 걸러졌습니다.
> **모델이 판단할 수 없는 기준으로 지시하면 그 지시는 없는 것과 같습니다.**

- [ ] 후보를 실제로 검색해서 시장이 있는지 확인했는가 (후기 수를 봤는가)

### 상품

- [ ] 미리보기 또는 시연을 준비했는가
- [ ] 부록·체크리스트처럼 바로 쓸 수 있는 게 들어 있는가
- [ ] 다른 기기에서 열어봤는가

### 판매 채널

- [ ] 결제와 전달이 한 덩어리인 곳인가, 아니면 전달 경로를 따로 만들었는가
- [ ] 수수료와 정산 주기를 확인했는가
- [ ] **본인이 직접 한 건 사봤는가** (다른 결제수단으로)

### 법

- [ ] 사업자등록 상태 확인
- [ ] 통신판매업 신고 여부 확인 (50회 미만 또는 간이과세자면 면제)
- [ ] 판매자 정보 7항목이 페이지에 다 있는가
- [ ] 전화번호는 공개해도 되는 번호인가 (개인 휴대폰 아닌가)
- [ ] 환불 규정에 전달 전/후/하자가 다 있는가
- [ ] **수익 보장 표현이 한 줄도 없는가**
- [ ] 부가세 포함/별도를 정했는가
- [ ] (법인 대상이면) 세금계산서 발행이 되는가

### 신뢰

- [ ] 후기 대체재를 최소 두 개 준비했는가
- [ ] 다루지 않는 것을 명시했는가
- [ ] 없는 실적을 있는 것처럼 흐린 곳이 없는가

### 가격

- [ ] (제품이면) 한정 수량과 인상 규칙을 정하고 공표했는가
- [ ] 현재 가격이 페이지에 계속 보이는가
- [ ] (대행이면) 시장 단가와 비교해봤는가

### 유통

- [ ] 단가에 맞는 접근을 고르고 있는가 (고단가 1:1 / 저단가 답변)
- [ ] 답변 글이 판매 글보다 많은가
- [ ] 판매 진행을 중계할 준비가 됐는가

## 부록 C. 확인 시점과 확인 방법 {: .page-break }

이 책의 수치는 전부 **2026년 7월에 확인한 것**이고 **바뀝니다.**

|---|---|
| 제작 대행 시장 단가 | 크몽·숨고에서 같은 품목 검색. **후기 수를 같이 보라** |

### 확인할 때 걸리는 함정 세 개

**하나. VAT 포함인지 별도인지 안 적힌 요율이 많습니다.**
3.63%(포함)와 2.73%(별도)를 나란히 쓰면 비교가 안 됩니다. 한쪽으로 통일하십시오.

**둘. "수수료"에 여러 종류가 섞여 있습니다.**
스마트스토어는 결제수수료와 판매수수료가 별개입니다. **더한 값으로 비교하십시오.**

**셋. 정산 시점을 수수료와 같이 보십시오.**
수수료 1%p 차이보다 정산이 2주 늦는 게 더 아플 때가 많습니다.
초기에는 그 돈이 다음 것을 만들 자금입니다.
