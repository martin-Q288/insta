# 72시간 판매 플레이북

인스타 카드 팩토리를 제품으로 팔아 **500만원**을 만드는 실행 문서.
영업·결제·납품은 사람이 해야 한다. 이 문서는 순서와 문안이다.

---

## 0. 먼저, 정직한 확률

목표를 티어 조합으로 환산하면 필요한 구매자 수는 이렇다.

| 조합 | 계산 | 합계 | 필요 구매자 |
|---|---|---|---|
| Studio 중심 | 149만 × 2 + 49만 × 4 | 494만원 | **6명** |
| 균형 | 149만 × 1 + 49만 × 5 + 19만 × 6 | 508만원 | **12명** |
| Basic 중심 | 49만 × 6 + 19만 × 11 | 503만원 | **17명** |

여기서 역산한다. 아래 전환율은 **가정**이고, 실제 응답이 들어오는 대로 갈아끼워야 한다.

```
필요 구매자                    6 ~ 17명
÷ 상담→구매 전환 25%     →  상담 24 ~ 68건
÷ 발송→상담 응답 7%      →  발송 340 ~ 970건
```

**72시간에 400~900건을 접촉해야 한다.** 하루 130~320건이다.
이게 이 미션의 진짜 병목이고, 여기서 갈린다.

그래서 결론은 두 갈래다.

- **기존 오디언스가 있다면** (팔로워, 고객 리스트, 단톡방, 이전 클라이언트)
  → 접촉 비용이 0에 가깝고 응답률이 훨씬 높다. 승산이 있다.
- **맨바닥에서 시작한다면**
  → 72시간 500만원 확률은 낮다. 대신 **Studio 티어 1~2건에 전부 건다.**
  6명 설득이 17명 설득보다 압도적으로 빠르다. 단가를 올리는 게 유일한 지름길이다.

스레드(4번)가 터지면 위 발송량이 크게 줄어든다. 하지만 **터지는 걸 계획에 넣지는 마라.**
안 터졌을 때도 굴러가는 계획을 세우고, 터지면 보너스로 받는 순서다.

숫자를 부풀려서 기분 좋게 만들 수는 있지만, 그러면 3일 뒤에 아무것도 안 남는다.

## 1. 레퍼런스가 0일 때 — 신뢰를 무엇으로 대체하는가

**72시간 안에 레퍼런스는 못 쌓는다.** 후기는 고객이 생긴 다음에 나오고, 고객은 후기가 있어야 생긴다.
이 순환은 안 깨진다. 그래서 레퍼런스를 만들려 하지 말고 **대체**한다. 신뢰의 종류는 하나가 아니다.

### 1-1. 고객 0명으로 만들 수 있는 신뢰 재료

| 재료 | 고객 필요? | 만드는 시간 | 힘 |
|---|---|---|---|
| **① 결과물 증거** — 도구가 뽑은 출력물 자체 | 없음 | 1시간 | 강 |
| **② 즉석 시연** — 상대가 준 소재로 그 자리에서 | 없음 | 상담마다 0 | **최강** |
| **③ 자가 적용 실측** — 내 계정에 돌린 실제 수치 | 없음 | 3일~ | 강 |
| **④ 위험 역전** — 안 되면 안 받는 구조 | 없음 | 30분 | **최강** |
| **⑤ 기술 근거** — 공식 Graph API, 파일 공개 | 없음 | 0 | 중 |
| 후기·레퍼런스 | **필요** | 2주~ | 강 |

**도구를 팔 때 후기는 대체 가능하다.** 사는 사람이 확인하고 싶은 건
"남들이 샀나"가 아니라 **"이게 되나"** 다. 컨설팅이면 후기가 필수지만,
물건은 눈앞에서 돌려버리면 끝난다.

### 1-2. ② 즉석 시연이 후기보다 강한 이유

후기는 조작할 수 있고, 보는 쪽도 그걸 안다. 그래서 후기는 항상 할인되어 읽힌다.
반면 **상대가 방금 준 링크로 그 자리에서 돌린 결과물은 조작이 원리적으로 불가능하다.**

그래서 모든 접점에 같은 문장을 박는다.

> "기사 링크 하나 주시면 그걸로 돌려서 결과물 보여드리겠습니다."

이게 이 판매의 중심 무기다. 랜딩페이지·콜드 DM·스레드 오퍼에 전부 이 문장이 들어가 있는 이유고,
**후기 0개로 149만원을 부를 수 있게 해주는 유일한 장치**다.

### 1-3. ③ 자가 적용 — 네가 첫 번째 고객이다

**지금 안 하고 있는 것 중 제일 큰 게 이거다.**
도구를 본인 계정에 돌려서 숫자를 만들면 그건 후기가 아니라 **데이터**다. 남의 허락도 필요 없다.

- 3일간 본인 계정을 이 도구로만 운영 → 인사이트 스크린샷 (도달·저장·팔로워 변화)
- 다국어 계정이 이미 있으면 **언어별 비교**까지 나온다. 대행사가 제일 궁금해하는 숫자가 이거다
- 3일치도 숫자다. "3일간 40개 발행, 도달 ○○" 로 기간을 밝혀서 쓰면 된다

주의 — 여기서 유혹이 온다. **수치를 부풀리면 ④ 위험 역전까지 같이 죽는다.**
인사이트 캡처는 검증되고, 대행사는 그 화면을 매일 본다.
낮은 숫자를 정직하게 쓰는 게 부풀린 숫자보다 강하다.

### 1-4. ④ 위험 역전 — 후기가 없을 때의 정공법

증거를 못 내놓으면 대신 **상대의 리스크를 없앤다.** 고가 B2B에서는 후기보다 이게 더 잘 먹힌다.

| 장치 | 문장 | 적용 |
|---|---|---|
| **첫 발행 보증** | "첫 게시물이 계정에 올라가는 것까지 확인하고 끝냅니다" | 전 티어 |
| **부분 후불** | "세팅 확인하시고 잔금 주세요" (선금 30 / 잔금 70) | Pro · Studio |
| **무료 시범 1건** | "귀사 소재로 1세트 만들어 드립니다. 아니면 없던 일로 하시면 됩니다" | Studio 대행사 |

무료 시범은 손해처럼 보이지만, 후기 0개로 149만원 계약을 따는 가장 현실적인 방법이다.
30분 써서 149만원 기대값을 사는 거래다.

### 1-5. 레퍼런스를 의도적으로 만드는 거래

첫 2~3건은 **돈 대신 레퍼런스를 받는다.** 이걸 숨기지 말고 명시적으로 거래하라.

> "지금 레퍼런스를 쌓는 단계라 솔직하게 말씀드립니다.
> Studio 149만원인데 **79만원**에 드리겠습니다.
> 대신 결과 나오면 **수치 공개와 후기**를 부탁드립니다. 부담되시면 안 하셔도 됩니다."

- 왜 싼지 설명이 되니까 **가격이 깎이는 게 아니라 이유가 생긴다**
- "첫 3건까지"라고 했으면 **진짜로 3건에서 멈춰라.** 계속하면 거짓 긴급성이고 반드시 들킨다
- 후기는 받는 즉시 랜딩페이지에 넣어라. 4번째 고객부터 정가다

72시간 매출로는 손해다. 그런데 이후의 판매 비용을 영구히 낮춘다.

### 1-6. 그래서, 누구부터 파는가

후기가 0일 때는 **증거를 덜 요구하는 순서**로 간다.

```
1. 아는 사람 · 이전 클라이언트   → 증거 = 나 자신
2. 즉석 시연이 가능한 상대        → 증거 = 눈앞에서 돌아가는 화면
3. Basic 19만원 구매자            → 19만원은 증거를 덜 요구한다
4. 콜드 Studio 149만원            → ④ 없이는 거의 안 된다
```

> **0번의 "Studio에 전부 걸어라"와 부딪히는 지점이 여기다.**
> 단가를 올리는 방향은 맞지만, 후기 0개로 콜드 149만원은 안 팔린다.
> 그래서 Studio를 노릴 때는 **무료 시범 1건 + 부분 후불을 같이 걸어야 한다.**
> 이 두 개가 후기의 자리를 메운다. 둘 다 없이 149만원을 부르면 그냥 무시당한다.

## 2. H+0 ~ H+4 — 팔 수 있는 상태 만들기

이 4시간을 건너뛰고 영업하면, 사겠다는 사람이 나타났을 때 받을 방법이 없다.

### 2-1. 결제 받을 수단 (30분)

| 수단 | 속도 | 수수료 | 비고 |
|---|---|---|---|
| **계좌이체 + 현금영수증** | 즉시 | 0원 | 가장 빠름. 개인 간 거래도 가능 |
| **토스 / 카카오페이 송금 링크** | 즉시 | 0원 | 링크만 보내면 됨. 소액 결제 마찰 최소 |
| 크몽 결제 | 심사 후 | 약 10~20% | 에스크로라 신뢰도 높음. 정산 지연 있음 |
| 세금계산서 | 사업자 필요 | — | 대행사·법인 상대는 이걸 요구한다 |

> **B2B를 노린다면 세금계산서 발행이 가능한지 먼저 확인하라.** 대행사·병원·법인은
> 증빙 없이 149만원을 개인 계좌로 보내지 않는다. 사업자가 없으면 Studio 티어의
> 최대 걸림돌이 이것이다. (개인이라면 원천징수 3.3% 처리로 협의 가능)

### 2-2. 납품 패키지 (1시간)

구매자에게 넘길 한 세트를 미리 만들어 둔다. 팔린 다음에 만들면 늦는다.

```
카드팩토리_납품/
├─ insta-card-factory.html      ← 도구 본체
├─ 시작하기.pdf                  ← API 키 발급 → 첫 발행까지 순서
├─ 라이선스.txt                  ← 1인/1사 사용, 재배포 금지
└─ 문의.txt                      ← 연락 방법, 질문 가능 기간
```

- 전달은 **구매자별 개별 링크**로. 공용 링크 하나를 돌리면 그대로 유출된다.
- `시작하기.pdf`는 화면 캡처를 넣어라. 글로만 쓰면 환불 문의가 이걸로 온다.

### 2-3. 랜딩페이지 채우고 올리기 (1시간)

`sell/landing.html`을 열면 **주황색 점선으로 표시된 자리**가 있다. 그대로 배포하면 안 된다.

- [ ] 카카오톡 채널 링크 (또는 오픈채팅)
- [ ] 이메일 주소
- [ ] 환불 규정 — 판매 채널 정책에 맞게
- [ ] 시연 가능 시간대
- [ ] 사업자명 / 대표자 / 사업자등록번호 / 연락처

호스팅은 GitHub Pages가 제일 빠르다. `sell/` 을 그대로 올리고
`https://<계정>.github.io/insta/sell/landing.html` 로 쓰면 된다.

### 2-4. 시연 영상 3분 (1시간 30분)

**이게 전환율을 가장 크게 움직인다.** 텍스트 설명 100줄보다 3분 화면 녹화가 낫다.

찍을 순서 — 기사 URL 붙여넣기 → 가져오기 → 생성 → 카드 나오는 순간 →
언어 탭 넘기며 3개 언어 보여주기 → 캡션 복사 → 게시.
편집 없이 한 번에 찍어라. 매끄러운 것보다 진짜인 게 중요하다.

## 4. H+4 ~ H+72 — 스레드 (상단 유입, 고분산)

전 기간 병행한다. 하루 30분씩만 쓴다.

**역할을 명확히 하자.** 스레드는 바닥을 깔아주는 채널이 아니다.
한 개가 터지면 크게 벌고, 안 터지면 0이다. 그래서 여기에 72시간을 다 걸면 안 된다.
바닥은 5번 아웃리치가 깔고, 스레드는 위쪽을 뚫는다.

| | 스레드 | 콜드 아웃리치 |
|---|---|---|
| 유입자의 구매 의도 | 없음 (스크롤 중) | 없음 (하지만 타깃이 정확) |
| 노출 비용 | 0원 | 시간 |
| 결과 분산 | **크다** — 0이거나 대박 | 작다 — 발송량만큼 |
| 주로 팔리는 티어 | Basic (19만원) | **Pro / Studio** |
| 심사·승인 | 없음 | 없음 |

**스레드만으로 500만원은 어렵다.** 대신 두 가지를 준다 —
Basic 다수 판매, 그리고 **아웃리치할 때 내세울 신뢰 근거**.
계정이 살아 움직이면 콜드 DM 응답률이 올라간다. 이게 두 채널을 같이 돌리는 실질적 이유다.

### 4-1. 계정 준비 (20분) — 새 계정으로 갈 것인가

**기존 계정이 콘텐츠 계정이면 새로 파는 게 맞다.** 판단 기준은 하나다.

| 기존 계정이 | 어떻게 | 왜 |
|---|---|---|
| 이슈·뉴스픽 등 **콘텐츠 계정** | **새 계정** | 팔로워는 충격 실화를 보러 온 사람들이다. 거기에 도구를 팔면 전환은 0에 가깝고, 콘텐츠 계정 도달까지 같이 깎인다 |
| 본인 이름·업계 활동이 쌓인 계정 | **그 계정** | 이력이 곧 신뢰다. 굳이 버릴 이유가 없다 |

**오디언스 미스매치는 이력 0보다 나쁘다.** 활동 이력이 신뢰를 만드는 건 맞지만,
잘못된 오디언스에게 파는 건 그 신뢰를 쓸 데가 없다는 뜻이다.

#### 새 계정의 구멍과 메우는 법

신규 계정의 문제는 **도달이 아니다** — 스레드는 팔로워 0에도 비팔로워 노출을 준다.
문제는 "이 사람이 누군지 확인할 방법이 없다"는 것, 즉 **1번 섹션의 레퍼런스 문제와
같은 구조**다. 그래서 답도 같다 — 선택할 필요가 없다.

**공개할 기존 계정이 있다면** 그게 제일 강하다.

```
판매용 새 계정   ← 여기서 판다
기존 콘텐츠 계정  ← 이게 포트폴리오다
```

첫 글에서 기존 계정을 공개하고 "이 계정들 운영하다가 도구를 만들었다"로 시작한다.
**후기와 달리 이건 조작이 안 된다** — 계정을 열어보면 확인되니까.

**공개할 계정이 없다면** 만드는 과정 자체를 근거로 쓴다. 첫 글은 이렇게 시작한다.

> 인스타 카드뉴스 한 세트 만드는 데 두 시간씩 걸리는 게 싫어서, 도구를 직접 만들었습니다.
>
> 기사 URL 하나 넣으면 카드뉴스랑 릴스가 10개 언어로 나옵니다.
>
> **내세울 실적은 아직 없습니다.**
> 만들면서 알게 된 것들을 여기 적겠습니다.

실적이 없다고 먼저 말하는 게 손해처럼 보이지만, **랜딩페이지가 "후기가 없습니다"로
시작하는 것과 같은 장치다.** 신규 계정에서 실적을 암시하면 반드시 검증 요구가 오고,
그때 못 내놓으면 계정이 끝난다. 없다고 먼저 말하면 그 공격이 아예 성립하지 않는다.

그리고 이 포지션은 3일차 오퍼와도 충돌하지 않는다 — "실적 없음"은 **내 계정 성과**에
대한 말이고, 파는 건 도구가 실제로 돌아간다는 사실이다. 그건 시연으로 증명된다.

#### 세팅 체크리스트

- [ ] 프로필 한 줄에 **뭘 하는 사람인지**. "인스타 콘텐츠 도구 만듭니다" 정도
- [ ] 프로필에 기존 운영 계정 핸들 (신뢰의 근거)
- [ ] 링크는 프로필에만. 본문에 박은 링크는 도달이 안 나온다는 게 운영자들 공통 경험이다
      (메타가 인정한 적은 없지만, 굳이 시험할 이유가 없다)
- [ ] **첫 2~3개는 손으로 올려라.** 팔로워 0인 새 계정이 첫날부터 API로만 발행하는 건
      굳이 만들 필요 없는 스팸 신호다. 자동화는 계정이 살아있는 걸 확인한 다음 켜라

### 4-2. 72시간 스케줄 — 가치 8 : 판매 2

판매 글을 먼저 올리면 그 계정은 거기서 끝난다. 순서가 전부다.
신규 계정은 **자기소개가 먼저**다 — 결과물 자랑으로 시작하면 팔이 계정으로 읽힌다.

| 구간 | 올릴 것 | 판매 언급 |
|---|---|---|
| **1일차** (H+4~28) | 자기소개 → 결과물 → 실패담 | **0** |
| **2일차** (H+28~52) | 문제 정의 → 무료 노하우 → 댓글 미끼 | 0 (DM 유입 시작) |
| **3일차** (H+52~72) | 시연 영상 → 오퍼 → FAQ | 여기서만 |

하루 3개. 10개씩 도배하면 도달이 깎인다.
시연 영상을 오퍼 바로 앞에 두는 건 의도적이다 — **증거 다음에 요청**이다.

### 4-3. 이걸 손으로 할 필요는 없다 — `threads/` 자동화

아래 8개 문안은 `threads/posts.md` 에 이미 들어가 있고, 공식 Threads API로 발행과
답글까지 자동으로 돈다. 세팅은 `threads/README.md`.

```bash
cd threads && npm install && cp config.example.json config.json
npm run check          # 게시 없이 토큰·키·글 길이 점검
npm run publish -- --dry
npm run loop           # 10분마다 발행 + 답글 대응 (무인)
```

- **일차 순서가 코드로 강제된다** — `day: 3` 인 오퍼 글은 3일차 전에는 안 올라간다.
  publish 를 몇 번 돌려도 판매 글이 1일차에 나가는 사고가 안 생긴다.
- **답글은 검토 없이 바로 게시된다.** 환불 분쟁·법적 조치 언급·개인정보 요구·수익
  보장 요구만 `state/escalations.jsonl` 로 빠진다. 전부 자동으로 돌리려면 config 의
  `escalate` 를 비우면 된다.
- **한도는 API가 아니라 사람이 정한다.** API는 글 250건/일을 허용하지만 기본값은
  6건/일이다. 자동화의 가치는 양이 아니라 **새벽 3시 댓글에 10분 안에 답이 가는 속도**다.
- 브라우저 자동화(로그인 세션 조작)는 안 쓴다. ToS 위반이고 계정이 이 전략의 유일한
  자산인데 그걸 담보로 잡을 이유가 없다.

수익 보장 금지·없는 기능 금지는 답글 생성 프롬프트에 박혀 있고, 제품 사실은
`config.json` 의 `product` 에서만 읽는다. **도구를 고치면 거기도 같이 고쳐야 한다.**

### 4-4. 포스트 문안 — 그대로 써도 되는 8개

**① 결과물 훅 (1일차 첫 글)**

> 기사 링크 하나 붙여넣고 3분 기다렸더니
> 카드뉴스가 10개 언어로 나왔다.
>
> 한국어 일본어 영어 독일어 스페인어…
> 번역이 아니라 언어별로 새로 쓴 문장이다.
>
> 손으로 만들 땐 한 세트에 두 시간 걸렸는데.

→ 결과물 이미지 4장 첨부. **이미지가 없으면 이 글은 안 먹힌다.**

**② 문제 정의**

> 인스타 계정이 안 크는 이유, 전략이 아니라 생산량이었다.
>
> 카드뉴스 한 세트 =
> 소재 찾기 + 문장 쓰기 + 이미지 고르기 + 자르기 + 캡션 + 해시태그
> = 두 시간
>
> 그래서 주 2~3회에서 멈춘다.
> 알고리즘 문제가 아니라 체력 문제였다.

**③ 노하우 무료 공개 (저장·공유가 여기서 나온다)**

> 스크롤 멈추게 하는 카드뉴스 제목, 패턴이 정해져 있다.
>
> 1. 숫자 + 반전 — "3주 만에 끊었다"
> 2. 손해 회피 — "이거 모르면 계속 손해"
> 3. 미완성 문장 — "의사가 말을 아끼는 이유는"
> 4. 통념 부정 — "물 많이 마시면 안 되는 사람"
> 5. 구체적 시점 — "어제 발표된 연구에서"
>
> 이걸 10개까지 채워두면 소재가 안 마른다.

**④ 실패담 (스레드에서 제일 잘 먹히는 형식)**

> 인스타 다국어 계정 만들다가 배운 것.
>
> 번역기로 돌려서 올린 계정은 도달이 안 나왔다.
> 같은 내용을 언어별로 새로 쓴 계정은 나왔다.
>
> 메타는 번역·불펌을 걸러낸다.
> "다국어로 올리기"가 아니라 "각 언어로 다시 쓰기"가 맞는 접근이었다.

**⑤ 시연 영상 (2일차 핵심)**

> 3분입니다.
> URL 넣고 → 생성 → 카드 나오고 → 계정에 게시까지.
>
> 편집 안 했습니다. 실제 속도입니다.

**⑥ 댓글 미끼 → DM 퍼널**

> 카드뉴스 니치별 후킹 구조를 문서로 정리해둔 게 있습니다.
> (일반 바이럴 / 건강 / 마인드셋 / 연예 4종)
>
> 필요한 분 댓글에 "구조" 남겨주세요. DM으로 보내드립니다.
> 파는 거 아니고 그냥 문서입니다.

> ⚠️ **진짜로 공짜로 줘야 한다.** 미끼만 던지고 DM에서 바로 판매를 꺼내면
> 그 순간 신뢰가 죽고 댓글에 그 말이 남는다. 문서 먼저 보내고, 대화가 이어지면 그때다.

**⑦ 오퍼 (3일차, 딱 한 번)**

> 위에서 보여드린 도구, 파일로 드립니다.
>
> 기사 URL → 카드뉴스 + 릴스 + 캡션, 10개 언어.
> 설치 없고 구독료 없습니다. HTML 파일 하나입니다.
>
> 19만원 / 세팅까지 해드리는 건 49만원.
>
> 수익은 보장 안 합니다. 줄여주는 건 제작 시간이고, 그게 파는 전부입니다.
> 궁금하신 분 DM 주세요. 원하는 기사 링크 주시면 그걸로 돌려서 결과물 보여드립니다.

**⑧ FAQ (인바운드 클로징용)**

> DM으로 제일 많이 받은 질문 두 개.
>
> "코딩 못해도 되나요"
> → 파일 더블클릭하고, 키 복사·붙여넣기까지 하시면 됩니다.
>
> "월 구독료 있나요"

> 대신 AI 문장 생성은 본인 API 키로 종량제입니다. 건당 수십 원 수준.

## 6. 시연 스크립트 (10분, 이게 클로징이다)

설명하지 말고 보여줘라. 그리고 **상대의 소재로** 돌려라.

```
0:00  "제가 설명하는 것보다, 올리실 소재로 직접 돌려보는 게 빠릅니다.
       주제나 기사 링크 하나 주시겠어요?"     ← 반드시 상대 소재로
1:00  URL 붙여넣기 → [가져오기] → 본문 채워지는 것 보여주기
2:00  니치 선택 → [콘텐츠 생성]
3:00  카드 나옴. 여기서 말을 멈춰라. 상대가 먼저 반응한다.
4:00  언어 탭 3개 넘기기 — "이게 번역이 아니라 언어별로 새로 쓴 겁니다"
6:00  릴스 탭 → 자막 붙은 9:16 영상
7:00  [게시] → 계정에 올라간 것 확인
8:00  "여기까지 8분입니다. 손으로 하면 몇 시간 걸리시죠?"
9:00  가격 3개 제시. 추천 하나만 말하라. 셋 다 설명하면 안 산다.
```

**클로징 한 문장:** "지금 계정 하나 붙여서 첫 발행까지 제가 끝내드릴까요?"

망설이면 가격을 깎지 말고 **1-4의 위험 역전을 꺼내라.** 순서가 있다.

```
1차   "선금 30%만 주시고, 세팅 확인하신 다음에 잔금 주세요"
2차   "그럼 귀사 소재로 1세트 먼저 만들어 드릴까요. 보고 결정하시면 됩니다"
```

깎아주면 제품 가치가 내려가고 다음 고객에게도 그 가격이 기준이 된다.
리스크를 대신 지면 가격은 그대로 두고 장벽만 사라진다. **후기가 없을 때는 이게 유일한 지렛대다.**

### 반드시 먼저 말해야 하는 것

숨기면 환불로 돌아온다. 먼저 말하면 신뢰가 된다.

- Anthropic API는 본인 키로 종량제 (건당 수십 원, 판매가에 미포함)
- 자동 게시에는 프로페셔널 계정 + 토큰 필요
- **수익은 보장하지 않는다.** 이 제품이 파는 건 제작 시간이다

### 세금

500만원은 신고 대상이다. 사업자 없이 개인으로 받으면 기타소득/사업소득으로
종합소득세 신고 의무가 생긴다. 사업자가 있으면 부가세 10%를 판매가에 포함할지
별도로 받을지 **미리 정해라** — 나중에 정하면 10%를 그냥 잃는다.

## 9. 이 미션이 끝나고 남는 것

72시간에 500만원이 안 되더라도, 제대로 하면 아래가 남는다.
사실 이쪽 기대값이 더 크다.

- 검증된 랜딩페이지 + 시연 영상 (재사용 무한)
- 크몽/숨고 등록 완료 → 이후 인바운드가 알아서 들어온다
- **스레드 오디언스** — 3일치 글이 계속 도달을 만든다. 다음 사이클은 발송 800건 없이 시작한다
- 실제 전환율 데이터 → 다음 사이클의 예측 가능성
- 콜드 아웃리치 리스트와 응답 이력
- **첫 유료 고객** — 이게 제일 크다. 0에서 1이 1에서 10보다 어렵다

스레드를 3일만 하고 접지 마라. 아웃리치는 멈추면 0으로 돌아가지만,
스레드는 쌓인 만큼 다음 판매의 비용을 깎아준다. 이 미션에서 얻는 가장 큰 자산이
매출이 아니라 이쪽일 가능성이 높다.
